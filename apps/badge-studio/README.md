# Badge Studio · 同心圆徽章工作台

**应用版本：2.2.1｜配置 Schema：v3**

StudioKit 的第一个正式工具。它是一个不依赖构建工具或第三方 CDN 的纯前端单页网页工具。

## 功能

- 上半圆、下半圆、左侧 9 点、右侧 3 点、中心文字五区独立设置。
- 根据字符实际字宽计算弧长；上下弧线分别调节间距、字号、字体、粗细、颜色、半径与 X/Y 偏移。
- 下半圆朝向圆心时自动反序；文字环旋转与朝向模式可调。
- 支持控制点拖拽、语义磁吸、辅助线、撤销/重做。
- 每个方案独立设置阴影、金属感明暗渐变；新建、复制、重命名、删除多个方案。
- 并排对比、Overlay 叠加预览与透明度控制。
- 导出透明背景 PNG、SVG、可内嵌上传字体的 SVG；选中方案批量 ZIP 导出。
- 版本化 JSON 配置导入/导出（包括上传字体的备份），浏览器本地自动保存。

## 在 StudioKit 中的位置

- 门户入口：`/`
- 工具入口：`/apps/badge-studio/`
- 页面文件：`apps/badge-studio/index.html`
- 共享导航只在页面顶部增加 StudioKit 返回入口；核心编辑器仍在本文件中独立运行。

## 本地运行

在仓库根目录执行：

```powershell
python -m http.server 8000
```

访问 `http://localhost:8000/apps/badge-studio/`。

## 配置、备份与隐私

- 所有编辑计算与 PNG/SVG 导出都在浏览器内完成；没有项目自己的服务器端接口或账号系统。
- 自动保存使用浏览器 `localStorage`。浏览器的 `file://`、`localhost` 和 GitHub Pages 来源彼此独立。
- 当前自动保存键为 `concentric_badge_editor_autosave_v2`。为兼容旧部署，后续不得随意改名；若要迁移，必须双读旧键并测试。
- 换电脑、换浏览器或迁移网址前，先使用“导出配置 JSON”，再到新网址导入。
- JSON 备份可能包括上传字体的 Base64 数据；请妥善保存，并确认有权使用和分发该字体。
- 页面不提供云端账号、跨设备实时同步或多人协同。GitHub Pages 只托管网页文件，不托管编辑结果。

## 已知边界

- SVG 中的文字默认仍是文本，并非真正的字体轮廓。内嵌字体 SVG 的兼容性取决于第三方查看器。
- 系统字体只有在运行设备上已安装时才能完全还原。
- PNG 最大设定尺寸为 8000×8000；较大图片、批量导出和复杂投影会消耗更多内存。
