# Badge Studio · 同心圆徽章工作台

StudioKit 的第一个工具：在浏览器里排版同心圆徽章（弧形文字 + 中心图形 + 内外环），支持多方案对比，并导出透明 PNG / SVG。纯前端单页，无构建工具、无第三方 CDN、无后端。

## 功能

- **五个文字区域独立设置**：上半圆、下半圆、左侧 9 点、右侧 3 点、中心。每个区域可单独设置字体、字号、粗细、颜色与 X/Y 偏移；弧形区域另有字间距与半径偏移。
- **按字符真实字宽计算弧长**：用 `measureText` 逐字测得宽度后累积换算成角度，不是按字符数均分，因此中英文混排、等宽与比例字体都能贴合。
- **下半圆朝向圆心时自动反序**，另有文字环旋转（−180°…180°）与朝向模式（`lower-inward` / `upper-inward` / `outward` / `inward`）。
- **控制点拖拽 + 语义磁吸**：拖拽画布上的控制点调整位置，磁吸可命中 3 / 6 / 9 / 12 点方向、同环相邻区域对齐、水平垂直轴、各环半径与网格；阈值、网格步长与各磁吸开关可在面板内调整。
- **辅助线与布局告警**：显示控制点、参考线与对齐提示；弧形文字跨度或外环超出画布时给出「可能重叠 / 可能被裁切」的布局告警。
- **多方案管理**：新建、复制、重命名、删除方案；每个方案独立设置阴影与金属感明暗渐变（对应 SVG `filter` / `gradient`）。最后一个方案不可删除。
- **并排对比与 Overlay 叠加**：方案分页切换、并排预览，以及带透明度滑杆（0.1–1，步进 0.05）的叠加预览。
- **撤销 / 重做**：最多 100 步，覆盖拖拽、参数编辑、方案操作与导入。
- **上传字体**：加载本地字体文件（`FontFace`）后应用到当前区域、全部区域或重置；字体数据随配置一起保存与导出。
- **版本化 JSON 配置导入 / 导出**，以及浏览器本地自动保存。

## 操作与快捷键

| 操作 | 方式 |
| --- | --- |
| 撤销 | `Ctrl` / `Cmd` + `Z` |
| 重做 | `Ctrl` / `Cmd` + `Shift` + `Z` 或 `Ctrl` / `Cmd` + `Y` |
| 拖拽控制点 | 画布上直接拖动（偏移量限制在 ±300） |
| 清除本地自动保存 | 自动保存区旁的「清除本地自动保存」按钮 |

快捷键在输入框内自动让行，不会抢走文本输入。

## 排版模型与数值边界

| 项 | 范围 / 默认值 |
| --- | --- |
| 画布尺寸 | 300–1200（默认 800） |
| 外环直径 | 100–760（默认 520） |
| 内环直径 | 20–700（默认 260） |
| 环线粗细 | 默认 8 |
| 字号 | 8–400 px |
| 单区域文字长度 | ≤ 400 字符 |
| 区域 X/Y 偏移 | ±300 |
| 文字环旋转 | −180°…180° |
| PNG 输出尺寸 | 64–8000（默认 2000×2000） |
| 默认文案 | 上弧 `STUDIOKIT`、下弧 `BADGE STUDIO`、左侧 `•`、中心 `◎`（项目中性内容，不含个人信息） |

超出范围的值在界面输入、配置导入两条路径上都会被夹取到合法区间。

## 导出

- **透明背景 PNG**：按设定的输出尺寸绘制，非正方形尺寸按 `scale = min(w, h) / canvasSize` 等比缩放并用透明边补齐，不拉伸变形；默认文件名 `concentric-emblem`。
- **SVG**：矢量输出，文字仍是 `<text>` 文本（不是轮廓路径），便于二次编辑。
- **内嵌字体的 SVG**：把上传字体写成 `@font-face` 内嵌进 SVG，第三方查看器能否还原取决于其字体支持。
- **批量 ZIP**：分别提供 PNG 批量与 SVG 批量两个入口，打包选中方案；SVG 批量会强制内嵌已上传字体。勾选方式是各方案的对比勾选框。

## 配置、备份与隐私

- 所有计算与导出都在浏览器内完成；页面无 `fetch`、无 `XMLHttpRequest`、无第三方资源，唯一外部链接是导航条上的「源码 ↗」（点击才联网）。
- 自动保存在 `localStorage`，键为 `concentric_badge_editor_autosave_v2`（历史兼容标识）。写入为 250ms 防抖，进入页面自动恢复，写入失败（配额不足等）会给出提示。
- 浏览器来源彼此独立：`file://`、`localhost`、GitHub Pages 与 Cloudflare Pages 各自一套存档。**换电脑、换浏览器或换域名前，请先「导出配置 JSON」再到新站点导入。**
- 配置 JSON 结构：`{ format: "concentric-badge-editor", schemaVersion, appVersion, exportedAt, state }`；`state` 含全局参数、全部方案，以及上传字体的 Base64 数据。请妥善保存，并确认有权使用和分发该字体。
- 兼容策略：读取 v1 的 `settings` 结构会迁移为当前区域模型；v2 配置导入时按 v3 补齐新增字段默认值；未知字段在导入后保留并随下次导出写回；`format` 不匹配的文件会被拒绝。导出时写入的 `schemaVersion` 取 `max(当前 Schema, 导入配置的 Schema)`，因此前向导入的高版本配置不会被静默降级。
- 页面不提供云端账号、跨设备实时同步或多人协同；托管平台只托管网页文件，不托管编辑结果。

## 在 StudioKit 中的位置

- 注册表条目：`shared/tool-registry.json` → `id: "badge-studio"`，入口 `./apps/badge-studio/`，状态 `available`。
- 共享导航由 [`shared/site-shell.js`](../../shared/site-shell.js) 在页面顶部注入，包含返回 StudioKit 的链接、当前工具名、`LOCAL-FIRST TOOLS` 标识，以及指向 GitHub 源码的外部链接（仅点击时联网，不加载远程资源）。
- 核心编辑器仍在本文件内独立运行；`shared/` 只提供外壳与稳定样式，不参与绘制逻辑。
- `validate_site.py` 会守住 `APP_VERSION`、自动保存键与外壳元数据，防止误改；版本升级需同时更新注册表、`docs/BASELINE.md` 与本目录 `CHANGELOG.md`。

## 本地运行

在仓库根目录执行（Windows 上若 `python` 指向 2.x 请用 `py -3`）：

```powershell
py -3 -m http.server 8000
```

访问 <http://localhost:8000/apps/badge-studio/>。直接双击 `index.html` 也能打开，但 `file://` 下自动保存属于独立来源，不可与线上存档互换。

## 已知边界

- SVG 中的文字默认仍是文本，不是真正的字体轮廓；内嵌字体 SVG 的兼容性取决于第三方查看器。
- 系统字体只有在打开页面的设备上已安装时才能完全还原。
- PNG 最大设定尺寸为 8000×8000；大图、批量导出与复杂投影会显著消耗内存。
- 没有打印样式、预设模板、多语言切换与主题切换；界面固定为 `zh-CN`。
- 批量导出严格按各方案的对比勾选执行；取消勾选的方案不会进入 ZIP。
