# Arcade 0.6.0 设计：星海关卡 Boss、弹种叠加、矿工瞄准线与显式全屏

本文件记录 0.6.0 的玩法设计、数据兼容、边界与回滚。仍为纯静态、零依赖、离线优先实现。

## 1. 黄金矿工

### 1.1 摆角与钩爪朝向分离

0.5.1 及以前，`tryAimAt` 直接把 `pend.angle` 对准目标并把 `pend.vel` 归零。命中正下方目标时摆角为 0、角速度为 0，收钩回到 `swing` 后停在垂直平衡位置；即使不恰好为 0，反复瞄准也会重置摆动能量，表现为摆幅越来越小、摆速变慢。

0.6.0 将状态拆成：

- `pend.angle` / `pend.vel`：钟摆的真实摆动状态，只在 `swing` 更新；
- `clawAngle`：绳索/钩爪当前朝向，`swing` 时跟随 `pend.angle`，瞄准/伸出/回收时指向目标。

`tryAimAt` 只设置 `clawAngle` 与 `pend.length`，不再修改 `pend`。收钩时 `ensureSwing()` 保留原摆动状态；若旧档或异常状态出现 `|angle|<0.12 && |vel|<0.25`，才补最小起步能量，避免死状态。这样连续瞄准不会损失摆幅/角速度，也不会出现垂直停摆。

`clawAngle` 写入既有 `runs:v1` 的 `data`；旧档没有该字段时回退为 `pend.angle`。

### 1.2 瞄准线（第四道具）

- 入口：工具条第四个按钮（快捷键 `4`），`aria-pressed` 表示开关。
- 显示：从矿工沿 `clawAngle` 画移动虚线，命中第一个物品时高亮圆环并标注价值；命中炸药显示红色警示。
- 计费：开启期间按游戏时间每秒扣 `$2`；暂停/结算不扣费；余额不足自动关闭并提示。HUD 显示 `-$2/s`。
- 存档：`aimLineActive` 写入 `data`；恢复时若余额不足自动关闭。
- 平衡：作为可选的付费辅助，不替代「指哪打哪」的有限次数；玩家需要在收益与信息之间取舍。

## 2. 全屏行为

0.4.0 曾实现“记住全屏选择，下次点开始/继续时自动恢复”。实际触控中，玩家点「开始游戏」「继续上次」也会触发 `overlay-panel` 的 `pointerdown`，被误认为全屏指令。0.6.0 移除此自动路径：

- 只有顶栏 `⛶`、键盘 `F`、弹层内「全屏模式」按钮会进入全屏；
- `prefs.immersive` 仍记录上次选择，但不再自动执行；
- 分享按钮与全屏按钮不参与任何自动触控。

## 3. 星海突击

### 3.1 关卡与 Boss

- 每关普通波次 30 秒（`STAGE_WAVE_SECONDS`），之后清空普通敌机、停止刷怪、进入 Boss 战。
- Boss 名称按关循环（赤焰旗舰 / 雷霆母舰 / 虚空堡垒）+ `MK.关卡`；尺寸 118×86。
- Boss HP：`700 + (关卡-1) * 300`；分数 `500 × 关卡`。
- Boss 入场后悬停在上方，左右缓摆；按血量分三档：
  - 100%–60%：5 发扇形瞄准弹；
  - 60%–30%：更快的扇形 + 10 发环形弹；
  - 30% 以下：7 发扇形 + 14 发环形弹。
- 顶部 HUD 显示 `STG n · BOSS`、Boss 名称与血条；击破后生命 +1、掉落 3 份 Buff、清空敌弹，短暂进入下一关。
- 玩家机体与 Boss 碰撞只扣血，不直接摧毁 Boss。

### 3.2 弹种叠加

- 普通双发始终存在；每种激活 Buff 在每轮追加自己的弹型：
  - 散射：3 发扇形；
  - 激光：1 发穿透高伤；
  - 追踪：2 发自动追踪；
  - 速射：额外中央弹 + 射击间隔降至 0.075s。
- Buff 不替换，只刷新自身持续时间；HUD 同时显示所有激活 Buff 的剩余秒数，玩家机体用多层光环表示叠加。
- 掉落优先选择当前未拥有的类型，避免“永远只掉同一个”。

### 3.3 移动范围

玩家可移动范围从原来的底部 380–710 扩展到 `46–714`，仅避开顶部 HUD；键盘、拖动与触控都走同一 clamp。Boss 与弹幕会在整屏范围内与玩家交互。

## 4. 数据兼容与回滚

- `runs:v1` Schema 不变；新增 `clawAngle` / `aimLineActive` / `stage` / `stageTime` / `buffs` / `lastBuff` 等字段都写在既有 `data` 内。
- 旧单弹种档（`weapon` / `weaponTimer`）在恢复时迁移成对应 Buff；旧矿工档缺少 `clawAngle` 时回退到 `pend.angle`。
- 回滚：恢复 0.5.1 的 `engine.js` / 游戏页即可；旧代码会忽略新字段。SW 版本需同步回退并清理缓存。

## 5. 验收

- 黄金矿工：连续 3 次瞄准后摆幅能量相对漂移 <15%；瞄准线开启 2.2s 至少扣 2 美元，关闭后不再扣费，0 余额无法开启。
- 星海突击：`spawnBossNow()` 生成 Boss，`damageBoss()` 清关后关卡 +1、生命与 Buff 掉落生效；玩家可移动到 y≤80；四种 Buff 同时存在且一轮齐射包含激光/追踪/散射。
- 全屏：保存 `prefs.immersive=true` 后，点开始/继续的 `pointerdown` 不得进入全屏。
- 布局：320px 下四个道具按钮仍可操作；续玩长摘要有 `min-width:0`，不撑宽中心页。
- `arcade_smoke.mjs` 66/66，`validate_site.py` / `build_site.py` / `node --check` 通过。
