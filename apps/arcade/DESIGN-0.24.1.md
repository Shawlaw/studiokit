# Arcade 0.24.1 — 生涯控制恢复、弹窗统一与 PWA 自动更新提示

- 版本链：0.24.1；SW 缓存键 `studiokit-arcade-0.24.1-v1`
- 基线：已发布 0.24.0，`main` 提交 `6744a3d`
- 验证口径：[`docs/arcade-life/INTEGRATION-0.24.1.md`](../../docs/arcade-life/INTEGRATION-0.24.1.md)

## 1. 目标

修复 Owner 试玩发现的三类回归，不改变生涯数据契约或经典玩法：

1. 折光港改版后丢失生涯设置入口，导致封存、解冻和完全重置难以发现。
2. 生涯正文滚动条贴近内容，二三级弹窗的标题栏、字体和颜色与一级弹窗不一致。
3. PWA 首页只依赖页面初次加载时的 SW 事件；新 SW 已被其他页面激活时，旧首页重新打开不会自动提示。

## 2. 实现与边界

### 2.1 生涯设置

- 折光港底部与街机厅首页页尾均可原地打开「生涯设置」，不跳转游戏页。
- 沿用既有 `freezeCareer` / `unfreezeCareer` / `resetAllCareer` API、二次确认和重置确认词，不新增存储字段。
- 封存后关闭折光港但保留设置面板；首页入口随状态立即更新。完全重置只清生涯库，经典 progress / runs / playtime / scores / challenge / meta / prefs 不变。
- 设置底部操作在港口数据刷新时保留同一 DOM 节点，关闭后恢复焦点；Esc 与遮罩只关闭最上层。

### 2.2 弹窗与滚动

- 钱包与收据接入共享 `CareerShell`；信箱与邀请显示共享标题栏，设置使用默认面板尺寸。
- 正文使用独立滚动区、`scrollbar-gutter: stable` 与右侧内边距；标题和港口底部操作不随正文滚动。
- 共享内容在生涯 shell 内使用同一组颜色 token，不修改经典游戏主题。

### 2.3 PWA 自动检查

- 首页初次打开、`pageshow` 和恢复可见时调用既有 `checkForUpdate()`，主动比较线上 `sw.js` 版本与页面 / SW 版本。
- 自动检查只显示更新横幅，不弹「已是最新」或失败 toast；60 秒内避免重复请求，保留手动检查。
- 不自动刷新、不强制更新、不改变 SW 消息协议、缓存迁移或离线行为。

## 3. 不变量

- 不新增 IndexedDB store / localStorage key / Schema；IDB v1 / 11 stores、`contentVersion 0.18.0`、`professionVersion 1` 不变。
- 不改经典游戏数值、关卡、积分、挑战或备份格式。
- 不新增远程资源、分析、后端或依赖。
- 旧版线索可访问性脚本与跨标签读信时间一致性断言的既有失败不在本版扩围修复，按基线对照如实记录。

## 4. 验证

实际门禁结果、基线对照与未验证项见 [`INTEGRATION-0.24.1.md`](../../docs/arcade-life/INTEGRATION-0.24.1.md)。真机 PWA 更新提示与生涯触控仍为 UNVERIFIED。

## 5. 回滚

- 数据层无需迁移；回滚前建议导出生涯档案，完全重置不可撤销。
- 代码层回退本版两个修复提交，并将版本链恢复为 0.24.0。若需在生产回退，使用新的递增修复版本和 SW 缓存键，确保已安装 PWA 能检测并切换制品。
- 自动更新检查与生涯弹窗修复相互独立，可分别回滚对应 HTML / UI 文件。
