# Arcade 0.7.0 设计：全游戏快乐道具、自然收尾与适度游玩

本文件记录 0.7.0 的玩法原则、数值、数据兼容、边界与回滚。实现仍为纯静态、零依赖、同源离线；本版本首先落在本地任务分支，不代表已经发布。

## 1. 产品原则：快乐不用赶进度

本轮不是加一套需要长期养成的系统，而是让每一小局更有选择、更有反馈、更容易在舒服的时刻结束：

1. **主动选择**：道具由玩家决定何时使用；不合适时可以不点，不自动消耗。
2. **固定补给**：每局给出确定次数，不靠抽奖、看广告、付费、签到或每日任务获得。
3. **减少浪费**：能持续生效的道具不重复扣次数；需要碰撞兑现的护盾/绞盘只在真正生效时消耗。
4. **自然收尾**：为适合的游戏加入 1–3 分钟目标或阶段收局点，不把“永远再玩一局”当成唯一目标。
5. **轻提醒、不强制**：单个游戏页有效游玩累计 20 分钟后最多提示一次；不锁定、不自动暂停、不反复催促，也不写“连续游玩天数”。
6. **不制造攀比**：最高分仍只在本机；不新增排行榜、分享成绩、每日目标或回归倒计时。

中心页新增「🎲 惊喜一下」：仅从 13 款已有游戏中随机打开一款，连续点击不重复上一款；没有额外奖励，不引导完成随机任务。

## 2. 共享道具 UI

### 2.1 `createToolbelt(definitions, options)`

`apps/arcade/engine.js` 新增 Arcade 内部共享 helper，不提升到全站 shared：

- `definitions`：`id` / `icon` / `name` / `description` / `getCount()` / `use()`，可选 `canUse()` / `active()`。
- `options`：`isPlaying()`、可选 `keys`、`label`。
- 返回 `{ element, buttons, sync }`；游戏自己拥有次数、效果与序列化，工具栏不隐式扣次数。
- 按钮使用 `textContent` 创建，带 `data-joy-tool`、剩余次数、禁用态、`aria-pressed`、说明与快捷键。
- 非游玩态、次数为 0 或 `canUse()===false` 时禁用；快捷键忽略重复事件、组合键与可编辑控件。
- 样式复用 `.toolbelt` / `.tool-btn`，位于画布内底部，低于开始/暂停弹层。

### 2.2 画布外控制区

星海底部机体、重力地板、影跃/雪铃平台与层塔倾斜计不能被道具遮挡，因此这些游戏和贪吃蛇使用 `.touch-pad.game-tools`；极速车道直接扩展既有 `road-pad`。另外，**记忆翻牌、2048、打地鼠、砖块计划、俄罗斯方块**五个原本放在画布内的道具栏，在 0.7.0 复审中发现会于 320×568 与横屏短舞台遮住挡板/棋盘/井底，现已统一改为 `createToolbelt(..., { placement: 'below' })`：道具行插在舞台之后、提示文字之前，`body.has-joy-row` 为它预留高度（单行 226px、双行 246px，≤360px 同样取值），不再占用画布逻辑坐标。所有道具按钮至少 44px，并提供 `data-joy-tool` 与 ARIA 说明。

`createToolbelt` 还补了复审提出的稳健性：快捷键统一小写（CapsLock 下仍生效）、忽略 `isComposing`、禁用态不吞按键、`getCount` 返回非有限数时失败关闭、`use()/canUse()/active()` 异常隔离、重复 id 跳过、空定义不插入空栏、返回 `destroy()` 清理监听器。

俄罗斯方块保留既有 5 个 `[data-touch]` 操作键，新增道具不混入该断言和左右手分区。

## 3. 每款游戏的道具与节奏

### 3.1 记忆翻牌

- 👀 **再看一眼 ×2**：显示未配对牌 1.2 秒，期间锁输入，不改原关卡预览计时。
- 💡 **灵犀提示 ×2**：武装后下一次有效首张翻牌消耗，配对牌只描边提示 1.5 秒，不自动得分。
- **节奏**：预览至少 0.6 秒后可点按跳过，防止误触，同时减少强制等待。

### 3.2 2048 合成

- 🧹 **小锤 ×2**：点选不超过 64 的方块移除，不额外生成方块、不加移动数或分数。
- ✨ **升一级 ×1**：点选 2–256 的方块翻倍，不额外生成方块、不直接加分，之后仍检查失败。
- **撤销公平**：道具操作可撤销，快照包含次数；旧快照缺次数时保留当前值，不能借撤销复制道具。
- **收尾**：首次合成 2048 后进入原本不可达的胜利结算，仍可继续挑战且只记录一次轮次；`winBonusClaimed` 保证 +2048 奖励与胜利弹层只发一次。

### 3.3 雪铃

- 🧲 **铃磁 ×2**：6 秒内碰撞半径增加 14 逻辑像素，不移动铃铛、不改生成器。
- 🎵 **安可 ×2**：接下来两颗不同铃铛得分翻倍，连击与高度分不加倍。
- **反馈**：命中显示浮分；同一铃铛仍只计一次。

### 3.4 砖块计划

- ↔ **宽板 ×1**：主动获得 10 秒加宽，已生效时不重复消耗；失球时只清除掉落拾取的宽板，主动买的宽板与剩余时间保留，并同步按钮状态。
- 🔨 **重锤球 ×1**：接下来 3 次真实砖碰把砖 HP 降为 1 后走原计分/粒子逻辑；墙和挡板不消耗。
- **收尾**：完成第 3 关即可圆满收局；旧档已超过第 3 关时不强行降级。

### 3.5 重力翻转

- 🛡 **相位护盾 ×1**：主动武装，下一次撞障碍才消耗，不扣命。
- 🧲 **星星磁铁 ×2**：8 秒、半径 180；只吸星星，不动障碍，空场或已激活不消耗。
- **收尾**：距离达到 3000m 穿过星门；`shortRun` 标记保证只有 0.7.0 新局启用，旧版无尽档恢复后不会被首帧强制收尾。

### 3.6 贪吃蛇

- 🫧 **慢速泡泡 ×2**：6 秒内有效步进间隔增加 0.06 秒，基础加速曲线不变，结束时不补跑积欠步数。
- ✂ **轻身剪 ×1**：剪去尾部 6 节，最短保留 3 节；长度不足时不消耗，不倒扣分数或果实数。
- **收尾**：普通与金果实合计 20 个即果园丰收；`shortRun` 标记保证旧版无尽档不会被首帧强制收尾。

### 3.7 打地鼠

- 🌟 **金鼠三连 ×1**：之后三次刷鼠固定为金鼠且不出炸弹，不改变全局概率或速度。
- 🛡 **安心锤 ×1**：6 秒内炸弹仍被敲走，但不扣心、时间或连击，炸弹不得分；45 秒总时长照常。
- **反馈**：显示实际得分与连击跳字。

### 3.8 俄罗斯方块

- 🔀 **换块 ×2**：交换当前块与 NEXT，不动 7-bag；出生位置冲突时不消耗。
- 🫧 **慢落 ×2**：6 秒内自然重力计时减半，软降/硬降及得分不变，不用一次补掉多格的方式恢复。
- **收尾**：新局 40 行达成胜利；旧档缺 `shortRun` 时按无尽局恢复，避免续玩时突然结束。

### 3.9 星海突击

- 💥 **电磁脉冲**：清空敌弹，普通敌机走原击坠逻辑，Boss 扣 100 HP；场上没有可作用目标时不消耗。
- 🛡 **星盾**：5 秒护盾，独立于受击无敌时间；两种道具上限均为 2，Boss 固定各补 1。
- **收尾**：每次 Boss 击破进入 CLEAR，可选「下一关」或「圆满收局」；结算只记录一次。CLEAR 状态会写入局内档，刷新继续后重新显示同一个选择弹层，不会静默进入下一关。

### 3.10 极速车道

- 🛡 **防撞气囊 ×1**：主动武装，真实撞车时才消耗，不扣命、不减速。
- 🫧 **车流慢放 ×2**：6 秒内敌车相对位移 ×0.55；玩家速度、里程与安全走廊预测不变。
- **收尾**：5000m 抵达终点；`shortRun` 标记保证旧版无尽档不被首帧强制收尾。

### 3.11 影跃

- 🪶 **羽落 ×2**：5 秒内仅下落阶段重力 ×0.35，最大落速降为 360，上升物理不变。
- 🌙 **月弹 ×2**：武装后下一次着陆起跳速度为 -768，之后恢复 -640。
- **反馈**：普通/移动/易碎平台分别显示“稳！/借势！/快跳！”。

### 3.12 层塔

- 📐 **垂线预览 ×3**：前 3 层免费教学结束后，可让下一箱显示落点投影；按下按钮只武装，真正释放时扣 1 次，暂停/离开不会白费。
- ⚖ **配重 ×2**：立即把倾斜角减半、角速度保留 25%，不取消物理倒塌；近乎稳定时不浪费次数。
- **反馈**：普通落点显示偏左/偏右及像素偏差。

### 3.13 黄金矿工

保留原有 🎯 指哪打哪 / ⏳ 加时 / 💪 强力绞盘 / 📐 瞄准线，不增加第 5/6 个按钮：

- 瞄准线仍按 $2/s，但只在钩爪摆动时计费；伸出、回收、暂停、结算不扣费。
- 强力绞盘从“上弦即扣次数”改为“夹物成功入账才扣次数”；抓空/TNT 不浪费，旧档不会恢复成负数；按钮补 `aria-pressed` 与上弦说明，重复点击给出提示。
- 夹中当帧显示物品与价值，回收中持续提示，入账仍只由原 `cashIn()` 执行一次。

## 4. 20 分钟一次性提醒

提醒复用 `Playtime` 的有效游玩时间片，而不是墙钟：

- 只有当前游戏页弹层关闭、页面可见且聚焦时累计；暂停、后台、失焦、开始与结算弹层不计入。
- 15 秒定期落盘不会重置提醒累计；提醒本身也不改变现有统计 key、轮次或时长。
- 达到 20 分钟时调用本地 Toast，提示可以喝水、暂停或带着成绩收工；每个页面生命周期最多一次。
- 不新增 localStorage key，不记录“被提醒次数”，不自动暂停。测试入口只在 `#test` 下开放。

## 5. 数据兼容与回滚

- `progress:v1` / `runs:v1` / `prefs:v1` / `playtime:v1` 的 key 与 Schema 全部不变。
- 新道具次数、计时器、武装和短局标记只存在对应 `runs:v1` 的 `data`；缺字段使用每局初始补给，存在字段逐项 `clamp`。
- 旧 2048 撤销快照缺道具字段时保留当前次数；旧俄罗斯方块档缺 `shortRun` 时按无尽局；矿工旧 `winchArmed=true, winch=0` 不允许消耗成负数。
- 消费、生效和 CLEAR 等关键节点立即 `saveNow()`，暂停/离开沿用原保存路径。
- 回滚可还原 `engine.js`、`arcade.css` 与 13 个游戏页；旧代码会忽略新 `data` 字段。SW 版本同步回退以清理新缓存，registry/README/CHANGELOG 一并恢复。

## 6. 验收

- 13 款游戏逐一验证按钮、次数、真实效果、禁用态与至少一个新增反馈/收尾；不只检查 DOM 存在。
- 每款验证缺新字段旧档可恢复；关键新状态经过暂停保存、刷新继续不丢失，撤销/碰撞不会复制或误耗次数。
- 共享工具栏与画布外控制区均验证鼠标/快捷键、禁用状态；20 分钟提醒只出现一次且不计暂停/后台。
- `validate_site.py`、`build_site.py`、`node --check` 与 `arcade_smoke.mjs` 全部通过。
- 320×568 / 375×667 / 390×844 / 430×932 与 CSS 沉浸模式无横向溢出，按钮不遮核心操作且触控目标至少 44px。
- 未执行 iOS/Android 真机试玩、系统分享和原生全屏时，必须保留 UNVERIFIED；自然目标的 1–3 分钟为设计估值，不冒充真人试玩结论。
