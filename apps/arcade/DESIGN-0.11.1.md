# Arcade 0.11.1 设计：恢复模糊蒙层结算 + 回看按钮按游戏命名

发布状态：本地实现（待发布）。基线：0.11.0（2026-11-21 双端发布）。

## 1. 背景

Owner 对 0.11.0 的两点反馈：

1. 16 款游戏的回看按钮都叫「回看棋盘」不合理——赛车、打地鼠、层塔等根本没有棋盘。
2. 既然已经做了独立按钮出口做模式切换，原来很显高级的模糊蒙层结算样式就应该保留，不该默认就去掉。

## 2. 改动

### 2.1 默认样式回归

- 结算弹层 `.overlay.is-result` 默认**保持 0.10.0 的高级模糊蒙层**（居中卡片、`background:rgba(7,11,24,0.72)`、`backdrop-filter:blur(2px)`），与开局/暂停弹层一致的视觉语言。
- 只有玩家点击面板内专用回看按钮、引擎加上 `.is-reviewing` 后，才去掉蒙层与模糊（`.overlay.is-result.is-reviewing { background:transparent; backdrop-filter:none }`），画布最终画面完整可见；右上角胶囊「查看结算」可唤回原结算卡片。
- `engine.js` 的 `setReviewHidden()` 同步切换 `.is-reviewing`；`hide()` 同时清理 `.is-result`/`.is-reviewing`。

### 2.2 按游戏命名的回看按钮

`show({ result })` 从布尔升级为「布尔或字符串」：

- `result: '回看赛道'` 等字符串直接作为面板内回看按钮文案；
- `result: true` 时退回通用文案「回看终局」（新游戏/兼容旧调用）；
- 引擎内 `reviewLabel` 记录当前文案，回看模式下按钮变为「查看结算」，恢复后还原。

## 3. 非目标

玩法、分数、存档 key/Schema、五子棋棋盘放大（0.11.0 已完成）、离线策略、路径兼容均不变。开局/暂停/错误弹层零改动。

## 4. 验收

1. 结算默认有模糊蒙层，按钮文案按上表；点按钮后蒙层消失、棋盘/场景完整可见，胶囊可恢复模糊结算。
2. `tools/arcade_review_test.mjs` 5/5：静态断言每款游戏文案与数量、运行时断言默认 blur 与回看透明切换、320/375/390/430 按钮 ≥44px。
3. 全量门禁、版本链 0.11.1、SW 缓存键 `studiokit-arcade-0.11.1-v1`、双端发布与线上验证。
