## 统一体验

- **由简到难**：每款游戏内部都有渐进难度（关卡、速度、障碍、敌机密度等）；中心页默认按难度排序，支持按类型筛选与关键词搜索。
- **全屏沉浸**：游戏顶栏 `⛶`（或键盘 `F`）或弹层内的「全屏模式」显式进入全屏。支持 Fullscreen API 的浏览器请求原生全屏并尝试锁定竖屏；不支持时（主要是 iPhone Safari）退化为 CSS 沉浸布局——隐藏站点导航、重复 HUD 与提示，保留紧凑标题，画布按 420:740 吃满可用空间，四周适配 `safe-area-inset-*`。**点开始/继续不会自动进入全屏**；退出全屏不会暂停或丢进度。
- **游戏内可以随时暂停。** 每款游戏顶栏都有暂停按钮，键盘 `P` / `Esc` 也可暂停。页面失焦或切到后台时自动暂停。俄罗斯方块在下方两组操作键之间另设暂停键，也可直接双击画布。
- **禅模式（俄罗斯方块）**：开始弹层第三入口，无限局（不设 40 行收局与关卡终点）；不冻结时速度随等级提升，按 `Z` 或道具坞「❄ 冻结提速」后速度停在当前等级、等级与行数继续累计，再按「▶ 恢复提速」立即追平。结算显示「禅模式结束」并把本局积分写入积分记录（**不写经典最高分**），刷新可恢复冻结状态与速度。
- **结算与回看**：带模式的游戏点「再来一局」会回到开始弹层重新选择经典 / 挑战 / 禅模式（以实际支持为准），而不是直接重开同一玩法；16 款游戏的结算面板都能回看最终画面。
- **触屏操作因游戏而异。** 俄罗斯方块左手横移，右手旋转、加速与落底。道具独立放在画布上方，PWA 和全屏的主控按钮在底部留出 72px 和安全区。贪吃蛇可用固定四向键，或在棋盘上滑够距离即提交一次转向。方向缓冲最多容纳两步，每格执行一步。极速车道提供变道按钮，其他游戏使用拖动或触摸操作。
- **游戏页左上角返回街机厅。** 全屏时用游戏顶栏的返回箭头。街机厅首页左侧可回 StudioKit。
- **小屏适配**：支持 320×568 / 375×667 / 390×844 / 430×932，使用 `safe-area` 内边距与动态视口高度；≤460px 时顶栏隐藏 DOM HUD、返回链接收成箭头，为全屏按钮留位，画布内的分数/关卡/时间 HUD 仍完整显示。全屏与 PWA 独立窗口的底部按钮统一抬升到拇指区（`--ac-thumb-lift`）。
- **局内进度本地可恢复**：每 3–4 秒自动保存一次，暂停或离开页面时立即保存。中心页把最近一局放在顶部，点「继续」直接恢复，其他存档可按需展开。从目录进入有存档的游戏时，仍可选择「继续上次」或「重新开始」。
- **游玩时长与轮次统计**：只累计真正处于游玩态的时间（弹层关闭且页面可见）；暂停、切后台、停在开始界面都不计入，机库等覆盖面板打开时也显式暂停计时。中心页汇总累计时长、今日、近 7 天与完成轮次，并按游戏列出时长、轮次与最近 30 轮明细。每 15 秒落一次总时长，每次落盘后自动开启下一段时间片，连续游玩不会在第一次落盘后停止累计。
- **积分记录表**：在目录下方的「游玩记录」里展开「积分记录」，可查看时间、游戏、模式、得分与详情。16 款游戏的常规对局和俄罗斯方块禅模式局自动计入。支持按游戏、按模式筛选，最新在前、最多展示 50 条，可单独清除。挑战模式使用独立的通关与最佳用时记录。
- **分享**：中心页「分享给朋友」分享合集链接；游戏弹层内分享当前游戏深链。优先调用系统分享面板（`navigator.share`），不支持时复制文案 + 链接；不读取或上传任何成绩。
- **安装与离线预载**：`manifest.webmanifest` + `sw.js` 让中心页可安装到桌面（Android / 桌面 Chrome、Edge、Safari「添加到主屏幕」）并以独立窗口启动。SW 安装时只缓存中心页外壳，16 款游戏由用户在中心页「预载全部游戏」显式缓存并显示进度。断网后可从中心页进入已缓存的游戏并返回，带 `.html` 和无后缀的游戏地址共用离线缓存。未预载的游戏显示离线提示页，版本更新后清理旧版本缓存；更新时按旧缓存里的预载清单重新联网取当前版本游戏页（0.19.0 起不再复制旧页面字节，避免新引擎配旧页面）。
- **中心页管理**：「惊喜一下」在目录顶部随机打开一款，连续点击会避开上一款。「游玩记录」里的「进度管理」支持清除单款或全部游戏记录，并可导出或导入 JSON 备份。页尾的「安装、离线与分享」提供应用安装、检查更新和离线预载。
- **生涯入口被动发现 + 身份建立后的常驻内容入口（0.21.1 已双端发布）。** 中心页始终展示经典目录：不再有生涯视图 / 默认视图切换，也不常驻告示板、信箱或章节 CTA。身份建立前，错过旧港来信时只在「继续上次」附近显示一行低强调小字（「旧港有一封来信」/「继续旧港来信」），点开深链显式阅读；未读 / 未投递线索不会自动创建生涯身份。**生涯身份一旦建立（已开生涯或已有章节），目录旁常驻「旧港生涯」入口，点击后在首页直接打开告示板弹窗（不再跳转游戏页），最小热区 44px；封存时隐藏内容入口与来信小字但保留页尾「生涯设置（已封存）」，解冻后恢复，完全重置后内容入口与设置入口一起消失。** 页尾小字入口仅用于封存 / 解冻、重置和档案，不是生涯内容 CTA；C0 之后保留游戏内章节入口与收据回流，经典目录与排序不受影响。设计见 [`DESIGN-0.21.1.md`](DESIGN-0.21.1.md)。
- **生涯封存、解冻与完全重置。** 从折光港底部或街机厅首页页尾的「生涯设置」原地打开面板。设置面板可封存生涯（保留全部数据与 live run，但禁止新线索、接单、继续委托与结算写入，事务内重读 `career-archive` 标记防旧标签绕过）并随时解冻（删除标记、推进代次、恢复原进度）。「完全重置生涯」需二次确认并输入「重置生涯」：单事务清空生涯库 11 个 store 与封存标记，**不触碰经典 progress / runs / playtime / scores / challenge / meta / prefs**，不可撤销，操作前应先导出档案。备份携带封存标记，replace 导入以文件状态为准；详细接口见 ADR §22。

## 星海突击（星域远征）

0.13.0 起，星海突击是唯一带**跨局成长线**的游戏；其余 15 款保持「无跨局成长」约定。三层循环：

| 层 | 内容 | 存档 |
| --- | --- | --- |
| 战斗（秒级） | 火力等级 1–5、能量与枯竭、弹种 Buff、临时编队、大杀器槽 | 局内自动存档（`runs:v1` 的 `data.run`） |
| 关卡（30s + Boss） | 波次 → Boss → CLEAR 三选一整备 → 下一关 | 局内自动存档 |
| 远征（跨局） | 结算星币 → 机库永久改装 → 下一局更强 | `studiokit:arcade:meta:v1` → `games['star-raid'].hangar` |

**机库改装（跨局）**：星币结算 `floor(score / 16)`（整备卡「军费补给 +40」另计），CLEAR 摘要显示「星币 +N」、结算弹层显示「+N 星币（机库共 M）」。机库内 `formula: 1` 锁定结算公式版本，避免以后改公式让老档语义漂移。开始弹层第三按钮与结算弹层第二按钮进入「机库改装」。

| 改装 | ID | 等级 | 效果 | 成本（星币 / 级） |
| --- | --- | --- | --- | --- |
| 装甲强化 | `hull` | 0–3 | 初始生命 +1，上限生命 +1 | 120 / 240 / 400 |
| 火力校准 | `power` | 0–5 | 全部子弹伤害 +6% | 80 / 160 / 260 / 380 / 540 |
| 引擎调校 | `engine` | 0–5 | 受击无敌 +0.12s/级、拾取吸附 +6%/级 | 60 / 130 / 220 / 340 / 480 |
| 反应堆 | `energy` | 0–5 | 能量上限 +10 | 90 / 180 / 300 / 440 / 600 |
| 弹仓扩容 | `bay` | 0–1 | 大杀器槽 +1（2→3） | 220 |
| 僚机中队 | `wing` | 0–3 | 编队时长 +2s、编队充能 +1 | 150 / 300 / 500 |

初始生命 = `3 + hull`，上限生命 = `5 + hull`；每关 CLEAR 回 1 生命但不超过上限。**星币只来自游玩得分**，没有内购、广告或签到式发放。

**局内火力等级 `power` 1–5**：双发 → 加中央 → 加两发内斜 → 加两发外侧 → 加中央重弹（单发 2 伤害）；射击间隔 0.13s → 0.127 / 0.124 / ≈0.117s。Boss 击破必 +1（封顶 5）、整备卡「火力核心」+1、重装敌机 30% 掉落；受击 `power = max(1, power - 1)`，不会退回白板。

**能量（油量限制）**：上限 `100 + 10 × energy改装`，开局满、跨关保留，CLEAR +40、Boss 击破 +45。基础消耗 1.2/s，「第二份起」的每种弹种 Buff +0.45/s，编队期间 +3.0/s，电磁风暴主题 ×1.6。恢复：击杀 +0.6/架、能量核心（普通击杀 7%，18 杀保底）+18、火力核心满级时转 +12 能量、道具槽满时拾取 +10。**能量 ≤0 枯竭**：射击间隔 ×1.8、伤害 ×0.7、移速 ×0.92、无法启动编队，HUD 红色警告；枯竭时被动回能 2.2/s，回到 25 解除，吃到能量核心立即解除。掉命时能量保底到上限的 40%，避免「掉命 → 没能量 → 再掉命」的死亡螺旋。

**临时编队**：初始充能 1 + `wing` 等级（上限 3），每局重置；启动（按钮 / 快捷键 3）消耗 1 充能，2 架僚机入场 `8 + 2×wing` 秒，跟随玩家 ±34px、每 0.22s 各射 1 发，各 2 点耐久可拦截敌弹后损毁；全部损毁或能量枯竭即结束，结束前 2 秒有浮字预警。

**大杀器（稀缺道具）**：槽位 `2 + bay`（最多 3），跨关携带、新开一局清空；稀有掉落 0.6%（核弹 / 轨道炮 / 时空锚同池，180 杀保底）与 Boss 后整备卡；触屏按钮或快捷键 4–7 使用。反物质核弹清空全部敌弹 + 全屏白闪强震屏；轨道炮 3.2s 垂直光柱（宽 28px 跟随玩家 x）；时空锚 5s 内敌弹 ×0.25、敌机 ×0.3、Boss 行动 ×0.55 并叠蓝色时停滤镜。

**6 星区主题轮转**：`themeIndex = (level - 1) % 6`，同一关固定不随机；压力轴各不相同而不是纯数值叠加，并各自带**分数补偿**（计入击杀 / Boss 得分与星币）。Boss 血量 `480 + (level-1) × 280`，再乘主题 `bossHp`。

| # | 主题 | 压力轴 | 效果 | 分数补偿 |
| --- | --- | --- | --- | --- |
| 1 | 巡逻星域 | 基础 | 无额外修正 | ×1.00 |
| 2 | 陨石带 | 走位 / 遮挡 | 每 4.2s 刷可击碎陨石（撞机扣命），敌机生命 ×1.05 | ×1.05 |
| 3 | 电磁风暴 | 能量 | 能量消耗 ×1.6，敌弹速度 ×1.12，星空电弧特效 | ×1.10 |
| 4 | 舰队封锁 | 数量 | 刷怪频率 ×1.22，重装敌机权重 ×2，敌机生命 ×1.08 | ×1.15 |
| 5 | 星云迷雾 | 视野 | 边缘暗角雾，敌弹速度 ×0.88、瞄准抖动 ±0.08rad，掉落率 +20% | ×1.10 |
| 6 | 母舰防线 | Boss | Boss 生命 ×1.35、射击间隔 ×0.9，普通刷怪 ×0.8 | ×1.20 |

**CLEAR 三选一整备**：Boss 击破后保留火力 +1、生命 +1（≤上限）、能量 +45、脉冲 / 星盾补给，并给 3 张整备卡。卡池 8 种：火力核心、装甲修复、能量电池、僚机补给、军费补给（本局结算 +40 星币）、核弹、轨道炮、时空锚（后三种仅在道具槽未满时进入卡池）。按局内种子确定性抽取（可回归、可刷新恢复），一次只选 1 张；主按钮「下一关」与次按钮「圆满收局」保持旧契约。

**弹种叠加**：拾取同种弹种改为 `min(180s, 剩余 + 固定时长)`（散射 12s / 激光 10s / 追踪 11s / 速射 9s），浮字显示本次增加与累计时长。能量消耗按激活种类数计算，所以长时间叠满四种要承担更高能量压力。

**星海割草（无尽演武，开始弹层第 4 按钮）**：四种弹种常驻、火力固定 MAX、大杀器 3 槽满载且使用后不消耗、脉冲 / 星盾 / 编队无限次；敌潮 0.26s 刷怪、同屏 32、血量 ×3.2，Boss 战 20 架护卫持续补充，掉落 12% 能量核心与大量火力核心 / 军械；Boss 四套专属弹幕（扇形齐射 / 螺旋星雨 / 交叉扫射 / 环爆三连）。受击只扣 22% 能量不掉命，**能量是唯一瓶颈**。该模式**不写分数、不给星币、不写局内档，也不参与最高分与积分记录**（真实游玩时长仍计入统计）；暂停 →「结束演武」退出。

**动画与反馈**：双层视差星空、关卡切换跃迁光带、主题染色、推进器拖尾与机身倾斜（只影响绘制）、敌机白闪、Boss 伤害数字、击杀冲击波、受击红屏闪、核弹白闪、Boss 入场警戒横幅、能量条低电量脉冲、编队入场光环与结束预警、陨石旋转、时空锚滤镜。全部读取 `A.reducedMotion` 降级（减粒子 / 取消震屏），不改判定与数值。

## 挑战模式

13 款游戏各有 6 关，共 **78 关**；二十一点 / 五子棋 / 纸牌接龙三款平和棋牌没有挑战模式。

- **入口**：开始弹层第二入口「挑战 6 关」→ 页面内选关面板（6 关按序解锁、显示最佳与通关标记、锁定态不可点）。经典 / 无尽仍是一级入口，挑战是第二种玩法，两种记录完全分离。
- **数据**：设计源在 [`docs/arcade/0.9/levels/`](../../docs/arcade/0.9/levels/)（目录里的 `0.9` 是**设计包版本**，不是应用版本）；由 `tools/arcade_09_data.mjs` 校验并生成运行时数据 `apps/arcade/challenge/<gameId>.js`（静态 `<script>` 加载，`file://` 可用；**不含参考解**，防剧透）。固定盘面 / 地图 / 时间轴 / 脚本，主路线不依赖随机。
- **记录**：独立 key `studiokit:arcade:challenge:v1`（每游戏 `cleared` / `best` / `assisted` / `collectibles`）。挑战**不写经典最高分、不写游玩轮次、不进积分表**；使用限量道具记为 `assisted`。
- **流程**：关卡目标与 HUD、暂停「退出挑战」、失败可归因 + 一次点击「重试本关」、通关结算（用时 / 最佳 / 收集 / 辅助标记）。挑战局存在 `runs:v1` 的 `data` 内（`mode` / `stageId` / `challengeState`），旧档缺 `mode` 时按经典恢复。
- **星海突击例外**：0.13.0 的机库改装、能量、大杀器等只作用于经典模式；**挑战 6 关数据与判定自 0.12.7 基线以来零改动**，挑战分支不读机库、不写星币。

`engine.js` 提供：固定步长游戏循环、物理辅助、粒子系统、WebAudio 合成音效、进度 / 局内 / 游玩统计 / 积分 / 挑战 / 通用游戏数据存储、暂停与续玩 UI 辅助、全屏与沉浸模式、游玩计时、分享与离线缓存封装，以及 `GAMES` 游戏清单。它是 **Arcade 内部**共享运行时，不是全站共享层。

## 数据与存储

全部为 `localStorage`，键都带 `studiokit:arcade:` 命名空间。既有键与 Schema 为历史兼容标识，**不得擅自改名**。

| 键 | 内容 | Schema |
| --- | --- | --- |
| `studiokit:arcade:progress:v1` | 每款游戏的 `{ high, plays, lastAt, lastScore }` | v1 |
| `studiokit:arcade:runs:v1` | 未完成的局内快照（每款一条，含 `savedAt` / `score` / `summary` / `data`） | v1 |
| `studiokit:arcade:prefs:v1` | 偏好：`muted` 静音、`immersive` 上次全屏选择、可选 `hallSort` 目录排序；`hallDefaultView` 为 0.21 前历史兼容字段，当前忽略 | v1 |
| `studiokit:arcade:playtime:v1` | 游玩统计：`ms` 总时长、`count` 轮次、最近 30 轮 `rounds`、最近 120 天 `days` | v1 |
| `studiokit:arcade:scores:v1` | 积分记录：最多 300 条 `{ at, gameId, mode, score, lines, level, durationMs, detail }` | v1 |
| `studiokit:arcade:challenge:v1` | 挑战记录：每游戏 `cleared` / `best` / `assisted` / `collectibles` | v1 |
| `studiokit:arcade:meta:v1` | 引擎通用游戏数据 `{ schemaVersion: 1, games: { <gameId>: {...} } }` | v1 |

- `meta:v1` 是 0.13.0 新增的**通用**容器（API `A.GameMeta.get/set/clear/clearAll/exportData/importData`），只存普通 JSON、单游戏 ≤32KB、损坏数据 fail closed 且不覆盖原值。目前只有星海突击使用：`games['star-raid'].hangar = { v: 1, formula: 1, credits, upgrades{hull,power,engine,energy,bay,wing}, runs, best }`。
- 备份 JSON 格式 `format: "studiokit-arcade-progress"`，含 `schemaVersion` / `appVersion` / `exportedAt` / `state` / `runs` / `playtime` / `challenge` / `scores` / 可选 `gameMeta`。旧备份缺某个字段时保留当前对应数据，导入失败整体回滚（含 meta key）。
- 道具次数、计时器与武装状态只追加在各游戏 `runs:v1` 的 `data` 内，不迁移 key、不改 Schema；旧档缺字段时按每局初始补给恢复。挑战局额外带 `mode` / `stageId` / `challengeState`。
- 版本号三处同步：`engine.js` 的 `ARCADE_VERSION`、`shared/tool-registry.json` 的 `version`、`sw.js` 的 `VERSION`（`validate_site.py` 与 `verify_deploy.py` 都会校验）。
- 无排行榜与云存档；分享只发送链接，不附带成绩。

## 已知边界

- **真机能力多为 UNVERIFIED**：iOS / Android 真机触控手感、原生全屏、系统分享面板、PWA 安装与更新提示时机、低端机帧率都未在真机上逐项确认。320/375px 下五子棋与纸牌接龙的单格约 14–20 CSS px，靠「先预览 / 选中、再确认 / 点目标」降低误触，实际手感待试玩裁决。
- **0.19.0 的紧凑模式与单手取值待真机裁决**：布局数据全部来自无头 Chrome 的模拟视口（375×548、390×664 是按 Safari 带工具栏的常见可见高度取的近似值）；半屏方向锁 40 逻辑像素、挡板增益 1.2、上滑影冲 56px / 350ms、结算防抖 450ms 是首版取值。门禁必须串行运行——多浏览器并发时会出现负载型偶发失败。
- **iPhone Safari 不支持网页元素全屏**，只能进入 CSS 沉浸模式，且无法隐藏 Safari 地址栏；更纯粹的显示需要「添加到主屏幕」。
- **无云能力**：无排行榜、无云存档、无跨设备同步；清除站点数据会丢失记录，请用 JSON 导出备份。
- **游玩统计**只统计正常结算的轮次明细，单款游戏保留最近 30 轮与最近 120 天日汇总，更早数据只保留总时长。历史上因 URL 识别失败记成 `0ms` 的轮次无法回填（0.13.3 修复后从下一局开始正常累计）。
- **PWA 与离线预载需要 HTTPS 或 localhost**；`file://` 下没有 Service Worker，只能在线游玩，不显示预载入口。iOS 可能回收长期未使用的站点缓存，重新联网打开并预载即可。
- **俄罗斯方块触屏按钮是固定右手布局**（左手横移、右手旋转 / 加速 / 落底），暂不支持左右手镜像或按键自定义，参考 [`DESIGN-block-controls.md`](DESIGN-block-controls.md)。
- **俄罗斯方块禅模式的「无限」** 指不设 40 行收局与关卡终点；井口堆满仍会结束本局（正常收尾，非失败）；冻结提速只停止速度随等级上升。
- **三款棋牌**：五子棋为启发式 AI，不提供难度档位、禁手与五手两打规则，也不保证不可战胜；纸牌接龙撤销历史不跨刷新（工具次数、选中与牌局会恢复）。
- **78 关的几何与内容密度**：0.9.0 只改运行时判定 / 提示 / 续档 / 计分，未重做关卡几何（俄罗斯方块 C04 与 C03 目标落点重复、2048 C05 一步可解、影跃参考通关 1.9–4.5 秒等问题仍在），需改设计源后另行排期。
- **星海突击**：星币与机库只在本机，只有经典模式结算星币与读取改装；改装上限固定（`hull` 3 / `power` 5 / `engine` 5 / `energy` 5 / `bay` 1 / `wing` 3），不设可无限叠加的成长。
- **画布逻辑分辨率固定 420×740**，横屏桌面以竖窗呈现。
