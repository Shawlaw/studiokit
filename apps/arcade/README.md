# 街机厅 Arcade

**应用版本：0.7.0（已双端发布）｜0.8.0 开发中：影跃「影冲 / 影之试炼」竖切片（未发布、未升版本）｜进度 Schema：v1｜局内存档 Schema：v1｜游玩统计 Schema：v1**

竖屏街机小游戏合集：网页加载后纯本地游玩，自带自研轻量物理引擎（重力、AABB/圆碰撞、单向平台、单摆积分、塔体倾斜力矩）。所有游戏由简到难、随时可暂停，并会把未完成的局内进度自动保存在本机。0.4.0 起支持全屏/沉浸游玩，黄金矿工加入限量主动道具与更平缓的起始摆速；0.5.0 新增游玩时长/轮次统计、分享、可安装 PWA 与手动离线预载；0.6.0 加入星海突击 30 秒关卡 Boss、弹种叠加与全屏纵向移动，黄金矿工瞄准线按秒计费，并修复瞄准后摆幅衰减与点开始误触全屏；0.6.1 修复 Boss 入场阶段穿过贴顶玩家的碰撞问题；0.6.2 修复黄金矿工目标金额小数，重排俄罗斯方块触屏按钮并区分「加速 / 落底」。

0.7.0 为全部 13 款游戏补充符合各自玩法的主动道具、即时反馈或自然终点，并坚持“快乐不用赶进度”：没有签到、每日奖励、付费抽奖、商店或跨局成长；道具每局固定补给，中心页可随机选游戏，连续有效游玩 20 分钟只提醒一次且绝不强制暂停。0.7.0 已双端发布（GitHub Pages + Cloudflare Pages，提交 `34f03df`，Actions `43274342320` 四个 job 成功，`tools/verify_deploy.py` 24/24 文件一致）。

## 0.8.0 开发中：影跃「影冲 / 影之试炼」竖切片（未发布）

0.8.0 的目标不是继续叠加道具和速度，而是让单款游戏先出现**明确目标、决策、可练习技巧、探索和即时反馈**。当前竖切片只改《影跃》，其余 12 款保持 0.7.0 现状；**版本号故意留在 0.7.0**，避免把未完成的 0.8.0 误标为已交付。

- **影冲（GP004）**：空中沿朝向的一次短水平冲刺（620px/s × 0.13s ≈ 80 逻辑像素，冲刺期重力 ×0.25，落地立即终止并保留 60% 惯性），**每次成功着陆补充一次**，开局/重开各有一次；不可用时不缓存。键盘 `Shift` / `J`，触屏为道具栏外的独立「💨 影冲」按钮（≥44px，可与画布左右半屏多指并发）；按钮数字/描边与画布左上「影冲 可用/已用」常驻状态、残影与柔和音效同步。旧无尽档缺少字段时按 1 次恢复，不丢局。
- **影之试炼（GP005）**：开始弹层主按钮仍是「开始游戏」（经典无尽，零回归），`btn2` 进入「影之试炼（S1–S3）」。S1 初入影林教左右惯性与落点预判，S2 月下断桥教移动平台相位与易碎窄台衔接，S3 影冲试炼在关键缺口强制一次影冲（无影冲几何上不可达，错冲会落回回收平台而非必死）。每关有顶部**影门**出口、失足 1 次点击从本关起点重试、暂停可退出本关；进行中状态写入既有 `runs:v1` 的 `data`（`mode/stageIndex/trialElapsed/trialScrolls/trialResults/...`），旧档缺 `mode` 一律按经典恢复；试炼**不写经典最高分、不写 Playtime 轮次**。
- **双路线与探索（GP006）**：S2 有「稳妥长路」与「近路快线」两条都可通关的路线（求解器实测理论最短 11.12s vs 7.88s），结算与三关总结显示路线标签；金色卷轴为**可选探索**（只记本局、不影响战力），失败复盘按关卡给出可归因提示与「卷轴是可选的」说明。
- **关卡数据与独立验证**：S1–S3 为手写常量（无随机），数据在 `docs/arcade/stages-0.8.json` 并在页面内 `STAGES-JSON` 标记块中内嵌；`tools/arcade_stage_solver.mjs` 以固定步长复刻游戏物理，证明三关可达、S3 必须影冲、错误冲刺可回收、卷轴不需要限量道具。设计/事实/量表/评审见 `docs/arcade/`（不进入发布产物）。
- **测试**：`tools/arcade_smoke.mjs` 85/85（经典与 13 款零回归）、`tools/arcade_gameplay_test.mjs` 11 个确定性场景、`tools/arcade_stage_solver.mjs` 三关 3/3 PASS。真机 iOS/Android 多指触控与真人试玩仍为 UNVERIFIED。
- **发布边界**：本竖切片仅在本地分支 `feat/arcade-0.8-gameplay`，未推送、未合并、未发布；是否继续做 S4–S6/其余 12 款，由 Owner 试玩反馈决定（见 `docs/arcade/0.8.0-PLAYTEST.md`）。

## 统一体验

- **由简到难**：每款游戏内部都有渐进难度（关卡、速度、障碍、敌机密度等）；中心页默认按难度排序，也支持按类型筛选和关键词搜索。
- **全屏沉浸**：游戏顶栏 `⛶`（或键盘 `F`）或弹层内的「全屏模式」按钮显式进入全屏；支持 Fullscreen API 的浏览器请求原生全屏并尝试锁定竖屏，不支持时（主要是 iPhone Safari）自动退化为 CSS 沉浸布局：隐藏站点导航、重复 HUD 与提示、保留紧凑标题，画布按 420:740 吃满可用空间，四周适配 safe-area。**点开始/继续不会自动进入全屏**，避免把普通触控误当成全屏指令；退出全屏不会暂停或丢进度。
- **随时暂停**：每个游戏顶栏都有暂停按钮，键盘 `P` / `Esc` 也可暂停；页面失焦或切到后台会自动暂停。
- **触屏友好**：俄罗斯方块采用双手分区按钮：左手 `← / →` 大键横移（按住连续移动），右手 `↻` 旋转、`↓` 按住加速、`⇓` 点按落底；加速按 0.06s/格逐格下落且按住时青色高亮，不会立即锁定；落底为实心金色按钮，点按立即锁定并带短促下沉/金色脉冲与轻震。每个按钮带图标与文字；画布不再承担隐藏触摸区，点按/按住画面不会误操作。极速车道提供左右变道按钮，一次点击只移动一条车道；其余游戏使用拖动、半屏触摸或滑动。
- **公平性与节奏**：星海突击按 4 阶段波次推进并设敌机/敌弹上限，每关 30 秒后进入 Boss 战，Boss 分三档火力并带血条；雪铃同一铃铛一局只计一次分；影跃只生成可达平台并延迟引入移动/易碎机制；极速车道生成时保留可达安全走廊；层塔前 3 层显示落点投影；黄金矿工前 5 关有不同物品池/炸药/摆速，并支持达标提前结算。
- **星海突击关卡与弹种**：屏幕内全区域纵向移动（顶部仅避开 HUD）；散射 / 激光 / 追踪 / 速射各自追加弹型并可与普通弹同时生效，HUD 显示剩余时间；每 30 秒普通波次后出现关卡 Boss，击破后生命 +1、掉落三份 Buff 并进入下一关。
- **黄金矿工限量道具**：底部道具条（触屏按钮 / 快捷键 `1 2 3 4`）提供 🎯 指哪打哪（点选金块或钻石，钩爪直线抓取，限量 2–3 次）、⏳ 加时（本关 +10 秒，上限 2 次）、💪 强力绞盘（下一次回收无视重量，上限 2 次）、📐 瞄准线（开启后显示当前钩爪方向与首个命中物，每秒扣 $2，余额不足自动关闭）。通关按关补给，不引入商店或货币；指哪打哪不会误抓炸药，点空或点炸药不扣次数。首关摆速由 520 降到 300，逐关 380/470/580/700，之后每关 +80、上限 1300。瞄准时只改变钩爪伸出方向，不打断摆角/角速度，连续使用不会缩小摆幅或让钩爪停摆。目标金额与 HUD 金额统一取整；画布顶部 HUD 使用深色渐隐衬托，子 HUD 的目标数字以金色胶囊突出。
- **小屏适配**：暂停按钮 44×44 CSS px，支持 320×568 / 375×667 / 390×844 / 430×932，使用 safe-area 内边距与动态视口高度；不再全页禁用缩放。≤460px 顶栏隐藏 DOM HUD、返回链接收成箭头，为全屏按钮留位；画布内的分数/关卡/时间 HUD 仍完整显示，最高分可在中心页或结算弹层查看。
- **局内进度本地可恢复**：每 3–4 秒自动保存一次，暂停/离开页面时立即保存；重新打开游戏会询问「继续上次 / 重新开始」。中心页「继续上次」区域会列出所有未完成进度。
- **游玩时长与轮次统计（0.5.0，0.5.1 修复计时连续性）**：只累计真正处于游玩态的时间（开始/暂停弹层关闭且页面可见），暂停、切后台、停在开始界面都不计入。中心页汇总累计时长、今日、近 7 天与完成轮次，并按游戏列出时长、轮次与最近 30 轮明细（时间、单轮用时、得分、新纪录标记）。游玩中每 15 秒落一次总时长，暂停/离开页面立即落盘；每次落盘后自动开启下一段时间片，连续游玩不会在第一次落盘后停止累计。
- **分享（0.5.0）**：中心页「分享给朋友」分享合集链接；游戏开始/暂停/结算弹层内「分享给朋友」分享当前游戏深链。优先调用系统分享面板（`navigator.share`），不支持时复制推荐文案 + 链接；不读取或上传任何成绩。
- **安装与离线预载（0.5.0）**：
  - `apps/arcade/manifest.webmanifest` + `apps/arcade/sw.js` 使中心页可安装到桌面（Android/桌面 Chrome、Edge、Safari「添加到主屏幕」），以独立窗口启动。
  - Service Worker 安装时自动缓存中心页外壳；中心页「预载全部游戏」逐项缓存引擎、样式、图标与 13 款游戏并显示进度。完成后断网仍可从桌面图标或中心页进入，未预载的游戏会显示离线提示页。
  - 离线缓存仅使用同源资源，不引入 CDN、分析或后端；更新版本后旧缓存自动清理，重新预载即可获得新版本。
- **中心页管理**：🎲「惊喜一下」随机打开一款且连续点击不重复上一款（不附奖励）；搜索、类型筛选、只看玩过、排序（推荐 / 难度 / 最近 / 最高分 / 名称）、单游戏清除、全部清除、JSON 导出/导入（含局内进度与游玩统计）。

## 文件结构

- `index.html` — 街机厅中心页：搜索/筛选/排序、继续上次、游玩统计、游戏卡片、分享/安装/离线预载、进度管理。
- `engine.js` — 自研共享运行时：固定步长游戏循环、物理辅助、粒子系统、WebAudio 合成音效、进度/局内/游玩统计存储、暂停/续玩 UI 辅助、全屏/沉浸模式、分享与离线缓存封装、游戏清单。
- `arcade.css` — 街机厅内部共享样式（深色街机主题、竖屏舞台布局、全屏沉浸布局、道具条、卡片网格、筛选栏、统计与离线面板）。
- `sw.js` — Service Worker：核心外壳预缓存、13 款游戏手动预载、离线导航回退与缓存版本清理。
- `manifest.webmanifest`、`icons/*.png` — PWA 清单与 192/512/maskable/Apple Touch 图标。
- `games/*.html` — 各游戏独立单页，互不影响；一个游戏出错不影响其他游戏。
- `DESIGN-0.4.0.md` — 全屏/沉浸与黄金矿工道具的完整设计、数值、兼容和回滚说明。
- `DESIGN-0.5.0.md` — 游玩统计、分享、PWA 与离线预载的数据模型、缓存策略、兼容和回滚说明。
- `DESIGN-0.6.0.md` — 星海关卡 Boss/弹种叠加、矿工瞄准线与显式全屏的设计、兼容和验收说明。
- `DESIGN-0.7.0.md` — 全游戏主动道具、短局目标、快乐约定、旧档兼容与回滚说明。

## 在 StudioKit 中的位置

- 注册表条目：`shared/tool-registry.json` 中 `id: "arcade"`，入口 `./apps/arcade/`，状态 `available`。
- 共享 shell：中心页引用 `../../shared/site.css` 与 `site-shell.js`；游戏子页位于 `games/` 深层，shell 返回链接由脚本自身 URL 推导站点根，任意深度可用。

## 本地运行

```
python -m http.server 8000
# 打开 http://localhost:8000/apps/arcade/
```

直接双击 `apps/arcade/index.html`（file://）也可游玩：游戏清单内联在 `engine.js` 中，无 fetch 依赖；但 Service Worker、安装提示与离线预载只在 `http://localhost` 或 HTTPS 下生效。

## 数据与隐私

- 无任何网络请求、埋点或第三方资源；音效由 WebAudio 实时合成。Service Worker 只缓存同源 Arcade 页面与 `shared/` 资源，不访问第三方域名。
- localStorage 键（均带 `studiokit:arcade:` 命名空间）：
  - `studiokit:arcade:progress:v1` — 全部游戏的 `{ high, plays, lastAt, lastScore }`（Schema v1；`lastScore` 为兼容扩展字段）。
  - `studiokit:arcade:runs:v1` — 未完成的局内进度快照（Schema v1，每款游戏一条，含 `savedAt` / `score` / `summary` / `data`）。0.7.0 的道具次数、计时器和武装状态只追加在各游戏 `data` 内；旧档缺字段时按每局初始补给恢复，不迁移 key、不改变 Schema。
  - `studiokit:arcade:prefs:v1` — 偏好（`muted` 静音、`immersive` 上次全屏选择；0.6.0 起仅记录，不再因点开始/继续自动进入全屏，旧对象缺少时按关闭处理）。
  - `studiokit:arcade:playtime:v1` — 游玩统计（0.5.0 新增，Schema v1）：按游戏保存 `ms` 总时长、`count` 完成轮次、`lastAt`、最近 30 轮 `rounds`（`at` / `ms` / `score` / `newHigh`）与最近 120 天 `days` 日汇总。旧版本没有该 key 时按空统计处理。
- 中心页支持导出/导入 JSON 备份（`format: studiokit-arcade-progress`，含 `schemaVersion` / `appVersion` / `exportedAt` / `state` / `runs` / `playtime`）。旧备份没有 `runs` 或 `playtime` 字段时仍可导入，并保留当前局内进度/统计；导入失败会回滚三个存储 key。
- `engine.js` 顶部的 `ARCADE_VERSION` 需与注册表 version 保持同步（`validate_site.py` 会检查）。

## 已知边界

- 无排行榜/云存档（离线优先约束，无后端）；分享只发送链接，不附带成绩。
- iPhone Safari 不支持网页元素全屏，只能进入 CSS 沉浸模式（隐藏站点导航、顶栏 HUD 与提示，保留紧凑标题；但无法隐藏 Safari 地址栏）；想要更纯粹的显示可“添加到主屏幕”。
- 黄金矿工的道具状态写在既有局内档 `data.tools` / `data.winchArmed` 中，仍是 Schema v1；旧档没有字段时按初始补给处理。
- 游玩统计只保存在本机：清除站点数据会丢失（请导出备份）；总时长包含未完成轮次，轮次明细只记录正常结算的局；单款游戏保留最近 30 轮、最近 120 天日汇总，更早数据只保留总时长。
- PWA 安装与离线缓存需要 HTTPS 或 localhost；`file://` 直接打开时 Service Worker 不可用，只能在线（本机文件）游玩，不显示预载入口。iOS 需手动「分享 → 添加到主屏幕」，不出现自动安装提示。
- 离线预载是显式动作：Service Worker 安装时只缓存中心页外壳，13 款游戏需点「预载全部游戏」。版本更新后旧缓存会被清理，需要重新预载；未预载的游戏断网打开时显示离线提示页。iOS 可能在一段时间未使用后回收站点缓存，重新联网打开并预载即可。
- 俄罗斯方块触屏按钮当前是固定右手布局（左手横移、右手旋转/加速/落底），暂不提供左右手镜像或按键自定义；布局参考与后续扩展见 `DESIGN-block-controls.md`。
- 本轮自动化覆盖 320/375/390/430 模拟视口与 85 项 CDP 检查（共享道具栏与一次性提醒、13 款游戏道具真实效果与旧档补给、显式全屏、矿工道具/瞄准线/摆动能量、星海 Boss/全屏移动/弹种叠加、方块双手按钮/画布不误触、刘海安全区、时长统计、分享兜底、安装清单、预载与断网回归）；未执行 iOS/Android 真机试玩与 5000/10000 次种子穷举，相关生成器结论为结构约束 + 采样验证，真机表现保留为 UNVERIFIED。
- 局内进度只保存在当前浏览器 localStorage；清除站点数据会丢失（请使用导出备份）。
- 画布逻辑分辨率固定 420×740，靠 CSS 等比缩放适配竖屏；横屏桌面以竖窗呈现。
- 0.8.0 影之试炼（开发中）：只在《影跃》内实现，其余 12 款仍为 0.7.0；试炼结果与路线标签只保留在本局 `runs:v1` 的 `data` 与界面上，**不建立跨局试炼解锁/记录**（是否符合期望由 Owner 试玩反馈决定）；试炼会累加既有 Playtime 的页面活跃毫秒数，但 `rounds/count` 轮次为空、不写经典最高分；死亡线采用“跌出当前镜头下沿”（镜头只上移），不是关卡几何底部；S2 路线判定为启发式（按落过的独占平台归类，可能把混合走法标为「混合」）；试炼结算**不区分 assisted**（是否使用羽落/月弹不单独标记）；清关瞬间会清掉本局自动存档，因此在「影门开启/试炼完成」结算页刷新会重新从 S1 开始、本局 results 不保留；真机 iOS/Android 双指并发（一手按住画布 + 一手点影冲）只做了 CDP/桌面合成验证，真机 UNVERIFIED。
