# Arcade 0.13.0 设计：星海突击 · 星域远征（机体改装 / 能量 / 编队 / 大杀器 / 关卡主题）

> 目标：解决 Owner 反馈的六件事——①每关都是白板装备 ②关卡难度没有差异 ③机体没有大升级与常态 buff
> ④想要稀缺的核弹级大伤害道具可以获取、携带、使用 ⑤引入油量/能量这类局限性 ⑥临时编队等出击状态；
> 同时把动画/打击反馈补足。**经典模式全部改动，挑战 6 关数据与判定零改动**。

## 1. 三个循环

| 循环 | 周期 | 内容 | 存档 |
| --- | --- | --- | --- |
| 战斗循环 | 秒级 | 自动开火、躲弹、吃弹种 Buff、能量管理 | 局内自动存档 |
| 关卡循环 | 30s + Boss | 主题星区 → 波次 → Boss → CLEAR 整备（3 选 1） | 局内自动存档 |
| 远征循环 | 一局 | 结算星币 → 机库永久改装 → 下一局更强 | 引擎游戏数据 key |

设计原则：

1. **不再白板**：局内火力等级、能量、道具、编队跨关携带；机库永久改装跨局继承。
2. **难度是主题差异，不是纯数值**：6 个星区主题轮转，每关一条不同的压力轴（数量 / 弹速 / 能量 / 视野 / Boss），
   主题同时给出分数补偿，避免玩家只刷最容易的关卡。
3. **稀缺资源要有取舍**：能量是射击与编队的预算，核弹是救场资源，编队充能是每局一次的战术选择。
4. **旧存档可读**：所有新增字段缺失时回退到默认值，不迁移、不中断旧局。

## 2. 机库（永久改装，跨局）

存储：引擎 0.13.0 通用游戏数据 `studiokit:arcade:meta:v1`（Schema v1，`games['star-raid'] = { hangar }`），
不再新增第二套 key；读写 API 为 `A.GameMeta.get('star-raid')` / `A.GameMeta.set('star-raid', { hangar })`。

```json
{ "hangar": { "v": 1, "formula": 1, "credits": 0,
  "upgrades": { "hull": 0, "power": 0, "engine": 0, "energy": 0, "bay": 0, "wing": 0 },
  "runs": 0, "best": 0 } }
```

- 星币结算：一局结束时 `floor(score / 16)` + 整备「军费补给」加成，写入机库；CLEAR 摘要显示「星币 +N」，
  结算弹层显示「+N 星币（机库共 M）」。`formula: 1` 锁定公式版本，避免以后调整公式改变老档语义。
- 入口：开始弹层第三按钮「机库改装」、结算弹层第二按钮「机库改装」。退出机库回到开始弹层。
- 备份：`Progress.exportText()` 自动带上 `gameMeta` 字段；中心页「清除记录」调用 `GameMeta.clear`；
  旧备份没有 `gameMeta` 时保留当前机库，导入失败整体回滚（含 meta key）。

| 改装 | ID | 等级 | 效果 | 成本（星币/级） |
| --- | --- | --- | --- | --- |
| 装甲强化 | `hull` | 0–3 | 初始生命 +1，上限生命 +1 | 120 / 240 / 400 |
| 火力校准 | `power` | 0–5 | 全部子弹伤害 +6% | 80 / 160 / 260 / 380 / 540 |
| 引擎调校 | `engine` | 0–5 | 移动速度 +6% | 60 / 130 / 220 / 340 / 480 |
| 反应堆 | `energy` | 0–5 | 能量上限 +10 | 90 / 180 / 300 / 440 / 600 |
| 弹仓扩容 | `bay` | 0–1 | 大杀器槽 +1（2→3） | 220 |
| 僚机中队 | `wing` | 0–3 | 编队时长 +2s，编队充能 +1 | 150 / 300 / 500 |

初始生命 = `3 + hull`；上限生命 = `5 + hull`；每关 CLEAR 回 1 生命但不超过上限。

## 3. 局内成长

### 3.1 火力等级 `power` 1–5

| 等级 | 主炮 | 单发伤害 | 射击间隔 |
| --- | --- | --- | --- |
| 1 | 双发 | 1 | 0.13s |
| 2 | 双发 + 中央 | 1 | 0.13s |
| 3 | + 两发内斜 | 0.9–1 | ≈0.127s |
| 4 | + 两发外侧 | 1 | ≈0.124s |
| 5 | + 中央重弹 | 2 | ≈0.117s |

- 来源：Boss 击破必 +1（封顶 5）、整备卡「火力核心」+1、火力核心掉落（重装敌机 30%）。
- 受击损失生命：`power = max(1, power - 1)`（保底不归零，避免回到白板）。
- 火力校准改装在最终伤害上 ×(1 + 0.06 × level)。

### 3.2 能量（油量局限）

- 上限 = `100 + 10 × energy改装`；开局满能量，跨关保留，CLEAR +40，Boss 击破 +45。
- 消耗：基础 1.2/s；每种「第二份起」的弹种 Buff 额外 +0.45/s；编队期间额外 +3.0/s；电磁风暴主题 ×1.6。
- 恢复：击杀 +0.6/架；能量核心掉落（普通击杀 7%，保底 18 杀）恢复 18；CLEAR +40、Boss +45。
- **能量 ≤ 0 枯竭**：进入枯竭态并强制结束编队；射击间隔 ×1.8、伤害 ×0.7、移速 ×0.92、无法启动编队；
  HUD 红色警告。枯竭时被动回能 2.2/s，回到 25 即解除；吃到能量核心立即解除。
- 受击（掉命）时能量保底 40%，防止「死亡 → 没能量 → 再死」的死亡螺旋。

### 3.3 临时编队

- 充能：基础 1 + `wing` 改装等级；整备卡「僚机补给」+1；上限 3。每局重置为初始充能。
- 启动（按钮 / 快捷键 3）：消耗 1 充能，2 架僚机入场 8 + 2×wing 秒。
- 僚机：跟随玩家左右 ±34px，每 0.22s 各射 1 发（伤害 0.8 + 火力修正）；各有 2 点耐久，
  可拦截敌弹（命中时白闪 + 碎片；全部损毁则编队结束）；能量枯竭立即结束。
- 结束前 2 秒浮动文字预警；HUD 显示充能数与剩余时间。

### 3.4 大杀器（稀缺道具，携带/使用）

- 槽位：2 + `bay` 改装（最多 3）；`items` 数组按槽保存，跨关携带，新开一局清空。
- 获取：稀有掉落 0.6%（核弹 / 轨道炮 / 时空锚同池，180 击杀保底）、Boss 后整备卡。
- 使用：触屏按钮 / 快捷键 4–7；使用后槽位清空。

| 道具 | 效果 |
| --- | --- |
| 反物质核弹 | 清空全部敌弹；普通敌机受 80 伤害；Boss 受 `max(120, min(260, 25% maxHp))`；全屏白闪 + 强震屏 |
| 轨道炮 | 3.2s 垂直光柱（宽 28px，跟随玩家 x），每 0.2s 对柱内敌机/Boss 造成 40/55 伤害 |
| 时空锚 | 5s 内敌弹速度 ×0.25、敌机速度 ×0.3、Boss 行动 ×0.55；蓝色时停滤镜 |

## 4. 关卡主题（6 星区轮转）

`themeIndex = (level - 1) % 6`，同一关固定，不随机。

| # | 主题 | 压力轴 | 效果 | 分数补偿 |
| --- | --- | --- | --- | --- |
| 1 | 巡逻星域 | 基础 | 无额外修正 | ×1.00 |
| 2 | 陨石带 | 走位/遮挡 | 每 4.2s 刷陨石（HP 4+，撞机扣命，可被击碎），敌机生命 ×1.05 | ×1.05 |
| 3 | 电磁风暴 | 能量 | 能量消耗 ×1.6，敌弹速度 ×1.12，星空电弧特效 | ×1.10 |
| 4 | 舰队封锁 | 数量 | 刷怪频率 ×1.22，重装敌机权重 ×2，敌机生命 ×1.08 | ×1.15 |
| 5 | 星云迷雾 | 视野 | 边缘暗角雾，敌弹速度 ×0.88、瞄准抖动 ±0.08rad，掉落率 +20% | ×1.10 |
| 6 | 母舰防线 | Boss | Boss 生命 ×1.35、射击间隔 ×0.9，普通刷怪 ×0.8 | ×1.20 |

关卡基础缩放沿用 0.12：敌机生命 `+ (level-1)`、速度/弹速随关卡与波次环递增；主题只做乘法叠加。
Boss 血量按「白板 DPS × 可接受时长」重标：`480 + (level-1) × 280`（0.12 的 700/300 偏肉），再乘主题 `bossHp`。
主题名与规则同时显示在 HUD 与关卡横幅，不做暗改。

## 5. CLEAR 整备（3 选 1）

Boss 击破后：火力 +1、生命 +1（≤上限）、能量 +45、脉冲/星盾补给（旧行为不变），并给出 3 张整备卡：

火力核心（power +1）、装甲修复（+1 生命）、能量电池（回满 + 本局上限 +10）、僚机补给（+1 充能）、
核弹 ×1、轨道炮 ×1、时空锚 ×1、军费补给（本局结算 +40 星币）。

- 卡片由局内种子确定性抽取（便于刷新恢复与回归测试），同一次只可选 1 张；选完卡片区刷新为已选状态。
- 主按钮「下一关」、次按钮「圆满收局」保持旧契约（挑战/冒烟回归依赖）。

## 6. 动画与反馈

- 双层视差星空 + 关卡切换跃迁光带 + 主题染色（陨石褐 / 风暴青 / 母舰红）。
- 玩家：推进器粒子拖尾、左右移动机身倾斜（只影响绘制）、枪口闪光。
- 命中：敌机 70ms 白闪、Boss 伤害数字、击杀冲击波圆环、受击红屏闪、核弹白闪。
- 其他：Boss 入场警戒横幅、能量条低电量脉冲、编队入场光环与结束预警、陨石旋转、时空锚蓝色滤镜。
- 全部动效读取 `A.reducedMotion`，降级时减少粒子/取消震屏；不改变判定与数值。

## 7. 兼容与回滚

- 局内存档：`serialize()` 新增 `run` 字段（power/energy/items/formation/combo/creditsBonus/refit/seed/lance/freeze）；
  旧档缺失时按默认值恢复；挑战分支序列化结构不变。
- 引擎新增通用游戏数据 `GameMeta`（key `studiokit:arcade:meta:v1`，Schema v1）：
  只存普通 JSON、单游戏 ≤32KB、非法数据 fail closed；备份新增 `gameMeta` 可选字段，旧备份兼容、导入失败整体回滚；
  中心页「清除记录」同步清除。既有 `progress/runs/prefs/playtime/scores/challenge` 六个 key 与 Schema 不变。
- 回滚：删除 `studiokit:arcade:meta:v1` + 还原 `engine.js` / `star-raid.html` 即可；旧版页面会忽略 `run` 字段。
