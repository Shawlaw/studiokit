# Arcade 0.8.4 设计：棋盘优先画布 + 地铁单手暂停

> 版本：Arcade `0.8.4`（2026-11-17）｜数据 Schema：不变（沿用 0.8.1 的 `scores:v1` 与既有 5 个 key）
> 需求来源：Owner 试玩反馈①「道具区极大挤占了游戏画面」；②「暂停按钮不方便，主要在地铁上玩」；③「游戏画面占屏比还是太小，能再大些吗」。
> 前置版本：0.8.2 删除禅模式独立按钮行；0.8.3 只修共享 shell 顶部安全区。

## 1. 问题（0.8.3 实测）

1. **道具行在画布外**：44px 行高 + 8px 间距（经典另加 19px hint + 8px），375×667 上合计约 79px。
2. **画布内部空间浪费严重**：420×740 的画布里，井口只有 240×480 —— 画布 33% 是棋盘，其余是顶部标题带（120px 高）、右侧信息栏（100px 宽）、底部空带（140px 高）、左侧留白（30px）。
3. **结果**：375×667 上画布仅占屏幕 42.8%、棋盘只占 **15.9%**；320×568 上棋盘 13.3%；390/430 高屏上画布 64–69%、棋盘 24–26%。
4. **共享样式冲突**：`shared/site.css` 的门户 `.tool-icon`（46×46 图标卡）命中道具按钮同名 class，把 emoji 撑成方块。
5. **暂停不可达**：顶部暂停键位于屏幕 7–14% 高度，扶栏杆/单手持机时够不到。

## 2. 方案（0.8.4 终版）

1. **棋盘优先画布 340×610**：井口 240×480 从 `(8,46)` 排到 `(248,526)`，占画布高度 79%、宽度 71%（0.8.3 为 65%/57%）；右侧信息栏压到 76px（NEXT + 分数/行数/等级竖排），顶部信息带 46px（经典淡标题 / 禅与挑战两行小字），底部 84px 道具坞带。画布内不再有其它空区。
2. **道具坞**：绝对定位在画布底部带内（`left/right: 8px; bottom: 6px`，44px 高），经典/挑战 3 格（换块 / 慢落 / 暂停）、禅模式 4 格（+ ❄ 冻结提速）；点击、快捷键 `1/2/Z`、禁用态与冻结切换逻辑不变。
3. **画布高度**：桌面保留 hint，扣 `192px`（禅 `144px`）；触屏隐藏重复的整行 hint（按钮自带左移/右移/…文字），扣 `152px`（禅 `140px`）；≤360px 宽扣 `146px`（禅 `134px`）；宽度上限按 `340:610`。四档与桌面 `docH == vh`、0 溢出。
4. **拇指区暂停**：暂停键作为道具坞最后一格（屏幕约 78–85% 高度，右手拇指自然可达），并支持触屏**双击画布任意位置暂停**（320ms/30px 阈值，鼠标双击不触发）；顶部按钮、`P`/`Esc`、切后台自动暂停全部保留，三条路径共用同一 `pauseByUser()`（存局内档 + 「继续」弹层）。
5. **矮视口回退**：viewport 高度 ≤560px（横屏手机/矮窗口）时 `placeJoyDock()` 把道具坞放回画布外并移除 `has-block-dock`，保留 0.8.3 布局。
6. **修类名冲突**：街机厅道具图标 class 由 `.tool-icon` 改为 `.tool-glyph`（`engine.js`、`gold-miner.html`、`arcade.css`），门户 46×46 图标卡不受影响；13 款游戏道具按钮恢复 16px emoji。

同时实测：

- 五档 `docH == vh`、横向/纵向 0 溢出；道具坞顶始终在井口底边下方（不覆盖任何棋盘格）。
- 道具坞：经典 3 格、禅 4 格，均 ≥44×44、单行不换行（320 经典 63px/格、禅 47px/格）；暂停格点击即暂停，「继续」回到 playing；双击画面同样进入暂停。
- 禅模式画布高度与经典一致或略大（390/430 撞宽度上限），不再依赖「禅比经典高 ≥44px」的旧代理指标。
- 横屏 667×375 与 ≤560px 高视口：道具坞回到画布外，行为与 0.8.3 一致。

## 4. 兼容与回滚

- **数据**：不新增/不修改 localStorage key 与 Schema（`progress/runs/prefs/playtime/challenge/scores` 全部不变），禅模式存档字段不变。
- **玩法**：落块、消行、计分、挑战、禅模式、暂停、积分记录逻辑零改动；只改页内布局常量/绘制坐标/样式/少量暂停绑定、引擎图标 class 与一条共享选择器。
- **测试同步（有意变更的门禁）**：
  - `arcade_smoke.mjs`：井口坐标改为新画布（`526/610`）；道具行断言为「方块页不得越过井口」；触屏 hint 断言改为「应隐藏」；新增 1 项「拇指区暂停键（道具坞内） + 双击画面暂停」（320/375/390/430），门禁 86→**87**。
  - `arcade_zen_scores_test.mjs` ZS-04：道具坞按钮数 3→4（含暂停）、`visibleTools/visibleFreezes/visiblePauses` 分类断言；「禅比经典高 ≥44px」改为「经典画布比 0.8.3 基线高 ≥44px + 禅不低于经典 + 无溢出」。
- **回滚**：还原 `apps/arcade/games/block-drop.html`、`apps/arcade/engine.js`、`apps/arcade/arcade.css`、`apps/arcade/games/gold-miner.html` 与两个测试文件到 0.8.3 即可；无数据迁移。SW 缓存键随版本升级刷新。
- `#test` 钩子（`info/zenInfo/startZen/toggleZenFreeze/zenSetState/zenLineClearScenario/endZen`）字段不变。

## 5. 验收（DoD）

- 320/375/390/430 与桌面：经典棋盘面积比 0.8.3 大 58%–89%，画布占屏比不下降（375 51%、390/430 72–73%），`docH == vh`、0 溢出。
- 道具坞 3/4 格均 ≥44×44、不覆盖井口；换块/慢落/冻结/暂停真实点击、快捷键 `1/2/Z`、双击暂停、暂停/继续/结算、积分记录、存档恢复零回归。
- 门禁：`arcade_smoke.mjs` **87/87**、`arcade_zen_scores_test.mjs` **14/14**、`arcade_gameplay_test.mjs --suite=base --repeat=2` **22/22**、`validate_site.py` / `build_site.py` / 全部 `node --check` 通过。

## 6. 已知边界 / UNVERIFIED

- 真机 iOS/Android 触控（画布内坞的点击热区、棋盘格大小手感、emoji 字体差异）仍为 UNVERIFIED；以无头 Chrome 模拟视口验证。
- 桌面 `hover: hover` 检测在无头 Chrome 中被模拟为 `hover: none`，真实桌面的「隐藏道具坞」沿用共享 `.touch-pad` 既有规则，未单独实测。
- 双击暂停是触屏手势，未在真机抖动/多指场景实测；误触后一击「继续」即可恢复，不丢局。
- ≤560px 高视口（横屏、矮窗口）保持 0.8.3 布局，道具坞仍在画布外；这是为避免压住井口的有意取舍。
- 画布外的共享 shellbar（38px）与顶栏（44px）未改动；若要进一步放大，需要把信息栏移出画布或隐藏站点导航，属于下一轮设计决策。
