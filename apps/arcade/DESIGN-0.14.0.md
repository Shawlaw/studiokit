# Arcade 0.14.0 设计：星海突击弹种叠加 + 「星海割草」无尽演武

> Owner 本轮两点：①同种弹药 Buff 多吃时应**叠加有效时长**，不是重置；②新增一个“模拟割草”模式——
> 所有弹药 Buff 常驻、大杀器库满载、手动道具无限，同时敌人/掉落极其密集、Boss 招式更炫，
> 玩家唯一瓶颈是能量；该模式**不参与任何积分与货币获取**。名称由实现方定：**星海割草**（engine id `mow`，
> 界面副标题「模拟割草」）。

## 1. 弹药 Buff 叠加（经典 / 挑战 / 割草共用）

**旧行为**：拾取同种弹种执行 `buffs[type] = max(剩余, 固定时长)`。剩余比固定时长高时“看起来没吃到”，
比固定时长低时“被重置成固定时长”，都不是叠加。

**新行为（0.14.0）**：

```js
before = buffs[type];
added = WEAPONS[type].duration;        // 散 12s / 激 10s / 追 11s / 速 9s
after = min(180, before + added);      // BUFF_STACK_CAP = 180s
```

- 拾取浮字显示 `散射弹 +12s · 共 24s`；达到上限时额外提示 `叠加上限 180s`。
- DOM HUD / 画布 HUD 显示**剩余总时长**（`散24s`），不再只显示单次时长。
- 180s 是护栏不是玩法限制：正常节奏 15 次同类拾取才会触顶，主要防止坏档/HUD 无限膨胀。
- 能量消耗仍按「激活的弹种种类数」计算（2 种起每种 +0.45/s），因此叠加会延长高消耗状态，
  这是有意保留的取舍：想长时间吃满四种弹种，就要承担更高能量压力。
- 挑战模式共用同一套拾取函数；C01–C06 数据中每关同类 powerup 不重复，实际难度零变化。

## 2. 星海割草（模拟割草）

### 2.1 定位

- 入口：开始弹层第 4 个按钮「星海割草（模拟割草）」。共用引擎 `createOverlayUi` 新增的可选第 4 按钮；
  其余 15 款游戏不传 `btn4`，行为与旧版完全一致。
- **无尽演武**：没有 CLEAR 结算弹层，Boss 击破后自动进入下一潮；玩家随时暂停 →「结束演武」返回开始界面。
- **不记分、不给星币**：击杀/受伤/击破 Boss 均不写 `score`，不调用 `settleCredits` / `A.Progress.recordPlay`，
  不写 `scores:v1`、不更新最高分、不增加机库 `runs/best`；`serialize()` 在 `mode === 'mow'` 时返回 null，
  因此也不会写局内档或弹出「继续上次」。真实游玩时长仍计入 `Playtime`（时长是统计，不是积分/货币）。

### 2.2 恒定火力

| 项目 | 割草模式 |
| --- | --- |
| 弹种 | 四种常驻（`buffs[type] = Infinity`，不衰减；HUD 显示「常驻」/∞） |
| 火力 | 固定 LV5（画布显示 `火力 MAX`） |
| 大杀器 | 3 槽满载 `核弹 / 轨道炮 / 时空锚`；使用后**不消耗槽位**（无限次），每次消耗能量 |
| 电磁脉冲 / 星盾 | 无限次（按钮计数 ∞），每次消耗能量；星盾仍受 5s 持续时间限制 |
| 僚机编队 | 充能显示 ∞，不扣充能；启动消耗能量，编队期间继续额外耗能 |
| 生命 | 不掉命；受击改为扣除 22% 能量上限（能量归零时结束编队并进入正常受击无敌） |

### 2.3 能量（唯一瓶颈）

| 项目 | 数值 |
| --- | --- |
| 被动消耗 | `(1.2 + 3×0.45) × 2.6 ≈ 6.6/s`（四弹种常驻；实测另加击杀/核心收益后净消耗约 5/s） |
| 击杀回能 | +0.12 / 架 |
| 能量核心 | 12% 掉落（8 杀保底），每个 +7 |
| Boss 击破 / 进潮 | +30 / +24 |
| 手动消耗 | 脉冲 14 · 星盾 12 · 编队 16 · 核弹 30 · 轨道炮 24 · 时空锚 18 |
| 受击 | 扣 `maxEnergy × 22%` |
| 能量上限 | 沿用机库「反应堆」：100 + 10×level（最高 150） |
| 枯竭 | 沿用经典：射击间隔 ×1.8、伤害 ×0.7、移速 ×0.92、编队强制结束；2.2/s 回能到 25 解除 |

设计意图：不按按钮、不吃核心时能量稳定下滑；连续击杀 + 主动捡核心可以维持；一旦用核弹/编队/星盾
清场，就会明显消耗。能量见底后不会死亡，只会掉火力，所以“唯一瓶颈”成立。

### 2.4 敌潮与掉落

| 项目 | 数值 |
| --- | --- |
| 刷怪间隔 | 0.26s（随潮数加速），85% 概率一次两架 |
| 同屏上限 | 32 架（Boss 战保留 20 架护卫持续补充） |
| 敌人血量 | ×3.2（保证屏幕上真的有“草”可割，而不是一出场就被秒） |
| 掉落 | 击杀 12% 能量核心（8 杀保底）、重装敌机 50% 火力核心、2% 军械箱；Boss 掉落 10 能量核心 + 4 火力核心 |
| 拾取上限 | 90 件，超出回收最早掉落，避免粒子/文字过载 |
| 弹幕上限 | Boss 战 100 发（经典仍 60 发） |

### 2.5 Boss 招式与视觉

割草 Boss 血量 = 经典公式 ×2.6；入场不清场（与杂兵同时存在），Boss 战中杂兵以较低频率补充。

四套轮流发射的专属弹幕（每套独立配色 + 环形 telegraph + 粒子）：

1. **扇形齐射**：7+2×phase 发瞄准扇弹 + 两侧三连副炮；
2. **螺旋星雨**：4+phase 条旋转臂，每条 8+3×phase 发；
3. **交叉扫射**：左右边缘各 8+2×phase 发横穿弹 + 中央三连瞄准；
4. **环爆三连**：16+4×phase 发整圈环爆 + 中央三连。

视觉：Boss 外层旋转警戒环、双层径向光晕、金色侧翼炮塔；阶段转换有全屏闪白/震屏/冲击环；
受击弹保留专属颜色并带外发光。所有新增动效继续尊重 `A.reducedMotion`。

### 2.6 UI / 布局

- 开始弹层 4 按钮（开始 / 挑战 / 机库 / 星海割草），沿用共享弹层滚动；320px 下 4 个按钮均 ≥44px、无横向溢出。
- 割草 HUD：左上「割草 N」击坠数（不是分数）、右上 ∞ 生命标记、中央 `STG N · 星海割草`；
  能量条与「火力 MAX」保留；弹种行显示「常驻 · 散激追速」；Boss 名 + 当前招式在血条上方。
- 顶栏 DOM 隐藏「分数 / 星币 / 最高」，只留关卡（显示「潮N」）、火力、弹种。
- 道具行 6 列（3 主动 + 3 大杀器），军械按钮显示 `-30⚡` 等能量成本；空槽在割草模式不会出现。
- 暂停弹层：继续演武 / 结束演武，并明确写「不记分、不给星币」。

## 3. 兼容、存档与回滚

- 无新增 localStorage key / Schema；挑战、经典、机库、积分记录、游玩时长、备份格式均不变。
- 经典模式仍使用原 `Math.max` 语义以外的唯一变化是**叠加**（新需求），其余数值/弹道/结算零改动。
- 割草模式不写局内档；刷新页面回到开始弹层，不会出现残留的“继续演武”。
- 回滚：还原 `star-raid.html` 的 `grantBuff/MOW/startMow` 分支与 `engine.js` 的第 4 按钮支持即可；
  旧档/旧备份不受影响。
