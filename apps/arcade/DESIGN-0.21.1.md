- 基线：0.21.0（2026-11-26 已双端发布，main `28a0182`，Actions `45752833025` 全绿，双端 89/89 文件一致，SW `studiokit-arcade-0.21.0-v1`）
- 本地产品分支 `fix/arcade-career-entry-0211`。T142 恢复身份建立后的回港入口，T143 收尾首航交付与旧档回流。
- 状态为**本地修复，未发布**。版本沿用 0.21.1，SW 缓存键沿用 `studiokit-arcade-0.21.1-v1`。线上仍为 0.21.0。
- 各轮验证范围与结果见[集成与验证记录](../../docs/arcade-life/INTEGRATION-0.21.1.md)。

## 1. 问题与边界

- 0.21.0 把「中心页不要显眼生涯入口」实现成了「身份建立后也没有内容入口」，玩家读完首信、建立身份后无法从中心页回到旧港，只能依赖游戏内回流或记住深链。0.21.1 修正这一过度实现。
- 修正后中心页**仍然没有**生涯视图、默认视图切换，也不恢复 0.18.x / 0.20.0 的常驻告示板、信箱或章节链接；经典目录与排序记忆保持原样。
- 身份建立前保持被动发现：只有未读 / 已读未投递来信在「继续上次」附近的一行低强调小字（`?careerLetter=1`），不自动创建生涯身份、不弹窗、不切视图。
- 首航复审发现收据的下一单入口绕行、旧档回港可能停在宿主游戏、到港开场未回应具体旧物，以及「旧档案夹」的反馈与实际进展不符。T143 按下文验收。
- 沿用 0.21.0 的封存 / 解冻、仅生涯完全重置、选择式叙事与 `static` / `release` / `full` 门禁分层语义。

## 2. 入口状态机

中心页生涯只读探针沿用代次防竞态与 `pageshow` / `visibilitychange` 刷新。中心页与宿主页共用 `readHubEntry()` 读取状态，封存状态仍取自 `career-archive`。

| 生涯状态 | 常驻「旧港生涯」内容入口 | 来信小字 | 页尾「生涯设置」 |
| --- | --- | --- | --- |
| 无生涯库 / 无线索 / 身份未建立 | 隐藏 | 隐藏 | 隐藏 |
| 有未读或已读未投递线索，身份未建立 | 隐藏 | 显示（低强调，深链显式阅读） | 隐藏 |
| 档案和账册可用，未封存 | 显示「旧港生涯」，打开 `games/pendulum-tower.html?careerPanel=town` 后进入告示板 | 按未投递状态显示 | 显示「生涯设置」 |
| 有旧港进展，但档案残缺或无法唯一确认 | 点击后显示具体原因和返回街机厅入口，可从生涯设置导入原档 | 按未投递状态显示 | 显示「生涯设置」 |
| 已封存 | 隐藏（同时隐藏来信小字与结算线索） | 隐藏 | 显示「生涯设置（已封存）」 |
| 解冻后 | 恢复常驻内容入口 | 按未投递状态显示 | 恢复「生涯设置」 |
| 完全重置后 | 隐藏并移除 `href` | 隐藏 | 隐藏 |

- 内容入口是经典目录旁的一张可点卡片，最小热区 44px；隐藏时同时移除链接，避免残留可聚焦的无目标元素。
- 入口只做显式跳转，不自动投递、不创建身份、不改 `hallDefaultView` 等偏好，也不影响经典目录、排序、页尾管理与积分记录。
- 深链 `?careerLetter=1`、`?careerPanel=*`、`?story=1` 的封存门控与 0.21.0 一致。

## 3. 版本、数据与兼容

- T142 新增首页入口与卡片样式。T143 让首页与宿主页共用档案判定，并修正告示板、结算收据和首航文案。
- 不新增 / 修改 localStorage key、IndexedDB 版本 / 11 stores / `careerSchemaVersion`、生涯内容 `contentVersion 0.18.0`、`rulesetVersion`、玩法数值、委托奖励与关卡 / 挑战数据。
- 封存标记仍写在既有 `state` store。完全重置仍由 `resetAllCareer()` 单事务执行并保留退役标记。回港探针只读档案、账册和章节状态。
- 无 CDN、远程字体、分析 SDK、后端请求或第三方资源；离线缓存策略与 0.21.0 相同。

## 4. 验收条件

- 无线索 / 有库无线索 / 仅未投递线索时，内容入口始终隐藏；来信小字行为不变。
- 身份一建立（即使尚未完成 C0 或委托）即显示常驻「旧港生涯」入口，不恢复生涯视图切换；点击后打开 `?careerPanel=town`。
- 封存后内容入口与来信小字同时隐藏、页尾仍保留「生涯设置（已封存）」；解冻后内容入口恢复。
- 完全重置后内容入口与设置入口一起消失，经典目录仍可见且有 16 张卡。
- 内容入口在 320/375/390/430 四档窄屏不溢出、右侧不越界、热区不小于 44px；最终 `arcade_smoke` 117/117 已验证。
- 文档检查（静态校验、构建、README 链接、diff 空白）完成；不把 0.21.0 历史结果写成 0.21.1 实跑，不声称发布。

## 5. T143 首航与旧档验收

- 交付首单后，从收据主动作直接回告示板并接到下一单。剧情回信提供独立的次要动作，终局流程保留目标相符的入口。
- 从首页回港时，正常档与可唯一确认的完整旧档应打开告示板。残缺旧档应得到明确说明与返回入口，可通过生涯设置导入原档。读取首页与打开回港入口均不补建档案或账册。
- 投递后先看到寄信人的收件确认。二十一点由阿德回应单据，记忆翻牌由老周回应牌背存根。单一来源的续访保留回话，多来源旧档无法判定哪封曾投递时显示中性确认。「港口实习」仍是默认首单。「看看出航」默认收起，展开后才展示阿砾、免费租机说明和已解锁的「首次巡航」。巡航接单与机库继续走现有入口。
- 「旧档案夹」首次结算实际新解锁「差一张的照片」时，收据展示这项进展。重复交付和已经可接下一单的档案均不重复显示新解锁。
