## 1. 问题与边界

- 0.21.0 把「中心页不要显眼生涯入口」实现成了「身份建立后也没有内容入口」，玩家读完首信、建立身份后无法从中心页回到旧港，只能依赖游戏内回流或记住深链。0.21.1 修正这一过度实现。
- 修正后中心页**仍然没有**生涯视图、默认视图切换，也不恢复 0.18.x / 0.20.0 的常驻告示板、信箱或章节链接；经典目录与排序记忆保持原样。
- 身份建立前保持被动发现：只有未读 / 已读未投递来信在「继续上次」附近的一行低强调小字（`?careerLetter=1`），不自动创建生涯身份、不弹窗、不切视图。
- 不改 0.21.0 的封存 / 解冻、仅生涯完全重置、选择式叙事与 `static` / `release` / `full` 门禁分层语义。

## 2. 入口状态机

中心页生涯只读探针沿用 0.21.0 的代次防竞态与 `pageshow` / `visibilitychange` 刷新；`started` 由 `career.active || career.chapters` 判定，`archived` 来自既有 `career-archive` 标记行。

| 生涯状态 | 常驻「旧港生涯」内容入口 | 来信小字 | 页尾「生涯设置」 |
| --- | --- | --- | --- |
| 无生涯库 / 无线索 / 身份未建立 | 隐藏 | 隐藏 | 隐藏 |
| 有未读或已读未投递线索，身份未建立 | 隐藏 | 显示（低强调，深链显式阅读） | 隐藏 |
| 身份已建立（已开生涯或已有章节），未封存 | 显示「旧港生涯」，直达 `games/pendulum-tower.html?careerPanel=town` | 按未投递状态显示 | 显示「生涯设置」 |
| 已封存 | 隐藏（同时隐藏来信小字与结算线索） | 隐藏 | 显示「生涯设置（已封存）」 |
| 解冻后 | 恢复常驻内容入口 | 按未投递状态显示 | 恢复「生涯设置」 |
| 完全重置后 | 隐藏并移除 `href` | 隐藏 | 隐藏 |

- 内容入口是经典目录旁的一张可点卡片，最小热区 44px；隐藏时同时移除链接，避免残留可聚焦的无目标元素。
- 入口只做显式跳转，不自动投递、不创建身份、不改 `hallDefaultView` 等偏好，也不影响经典目录、排序、页尾管理与积分记录。
- 深链 `?careerLetter=1`、`?careerPanel=*`、`?story=1` 的封存门控与 0.21.0 一致。

## 3. 版本、数据与兼容

- 产品行为只改 `apps/arcade/index.html`（探针与内容入口节点）和 `apps/arcade/arcade.css`（`.hall-career-entry` 样式）；版本链与发布清单同步到 0.21.1，不改生涯数据 Schema 或门禁聚合脚本。
- 不新增 / 修改 localStorage key、IndexedDB 版本 / 11 stores / `careerSchemaVersion`、生涯内容 `contentVersion 0.18.0`、`rulesetVersion`、玩法数值、委托奖励与关卡 / 挑战数据。
- 封存标记仍写在既有 `state` store；完全重置仍由 `resetAllCareer()` 单事务执行并保留退役标记。0.21.1 只改变中心页对已有状态的呈现。
- 无 CDN、远程字体、分析 SDK、后端请求或第三方资源；离线缓存策略与 0.21.0 相同。

## 4. 验收条件

- 无线索 / 有库无线索 / 仅未投递线索时，内容入口始终隐藏；来信小字行为不变。
- 身份一建立（即使尚未完成 C0 或委托）即显示常驻「旧港生涯」入口，不恢复生涯视图切换；点击后打开 `?careerPanel=town`。
- 封存后内容入口与来信小字同时隐藏、页尾仍保留「生涯设置（已封存）」；解冻后内容入口恢复。
- 完全重置后内容入口与设置入口一起消失，经典目录仍可见且有 16 张卡。
- 内容入口在 320/375/390/430 四档窄屏不溢出、右侧不越界、热区不小于 44px；最终 `arcade_smoke` 117/117 已验证。
- 文档检查（静态校验、构建、README 链接、diff 空白）完成；不把 0.21.0 历史结果写成 0.21.1 实跑，不声称发布。
