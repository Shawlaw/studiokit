# 俄罗斯方块触屏按钮设计（0.6.2，已发布）

本文件记录 0.6.2 已发布批次中俄罗斯方块触屏按钮的调研、布局取舍、兼容与验收。改动只涉及输入与样式，不改变玩法、计分、DAS/ARR、存档 Schema 或 localStorage key。

## 1. 参考与共同规律

- **官方 Tetris 手游（PLAYSTUDIOS）**：App Store 描述把操作概括为 “Swipe to clear lines”，实际界面以滑动/点按为主，没有把移动、旋转、软降、硬降堆成五个等宽按钮。参考：<https://apps.apple.com/us/app/tetris/id1491074310>。
- **《俄罗斯方块环游记》社区布局推荐**：官方社区曾整理四套 DIY 布局，并明确建议萌新使用“左手方向 + 软降，右手旋转 + 硬降 + 保留”；喜欢双手平衡的玩家则用“左手左移/左转/硬降，右手右移/右转/软降/保留”。游戏允许调整按钮大小、透明度与位置。参考：<https://www.taptap.cn/moment/15225214266770396>。
- **经典掌机复刻 App**：左侧十字方向键、右侧大号旋转键，底部单独放开始/声音/重置。参考：<https://apps.apple.com/cn/app/id1626250521>。

这些产品的共同规律：

1. **按手分区**：移动与动作分别靠近左右拇指，而不是按功能排成一条等宽横排；
2. **动作键独立**：旋转/硬降与横移分开，硬降用颜色或尺寸强调，减少误触；
3. **少而大**：按钮数量控制在一屏可覆盖的范围，触控目标明显大于 44px；
4. **按住有用**：横移/软降支持按住连发，旋转/硬降保持单次点按；
5. **可调整**：成熟产品允许换布局；本轮先给出一个适合右利手的默认布局，并在文档中记录后续可扩展点。

## 2. 原实现的问题

- 五个 52×64 左右的按钮等宽排成一行，顺序是 `← ↻ → ↓ ⤓`；旋转夹在左右移动之间，左右手都不顺手。
- 移动与动作没有视觉分组，只有硬降换了颜色；纯图标对第一次玩的用户不够明确。
- 画布仍保留一套隐藏触摸区（左/右半屏横移、中列旋转、底部软降），与下方按钮重复；点画布会误移动/误软降，底部还写着“按住此区 = 软降”。
- 触屏与键盘提示混在两行里；按住横移时 `tryMove` 每格播放一次 UI 音效，DAS/ARR 连发会形成每秒约 20 次的叠音。

## 3. 本轮布局

```
┌───────────────┐          ┌──────────────────────┐
│  ← 左移  → 右移 │          │  ↻ 旋转  ↓ 加速  ⇓ 落底 │
└───────────────┘          └──────────────────────┘
        左手横移                        右手动作
```

- **左手 2 键**：`←` / `→` 做大，按住 DAS/ARR 连续横移；这是最高频的持续输入。
- **右手 3 键**：`↻` 旋转、`↓` 加速、`⇓` 落底；加速放在右手，左手可以同时按住横移，形成“贴墙下滑/边移边降”的组合。落底放在最外侧，使用实心金色按钮。
- **尺寸**：375px 及以上按钮 64px 高，320px 下 58px 高；320px 实测约 55×58，仍大于 44px 最小触控目标。每组内部间距 7px（320px 下 5px），左右两组之间保留 14px（320px 下 10px）的分隔。
- **标识**：每个按钮 = 大图标 + 2 字标签（左移/右移/旋转/加速/落底），`aria-label` 补充“按住连续移动/按住加速下落/点按直接落底并锁定”等操作说明。
- **提示**：触屏与键盘提示拆成两个 `span`，触屏只显示一行“按住 ← → 移动 · ↓ 按住加速 · ⇓ 点按落底”；键盘布局只在非触屏显示。
- **画布**：移除隐藏触摸区及“按住此区 = 软降”提示；画布只负责显示，所有操作统一走下方按钮。这样点按/按住画布不会再移动、软降或旋转。
- **音效**：`tryMove` 增加 `silent` 参数；DAS/ARR 自动连移静音，只在第一次按下或换方向时播放 UI 提示音。

### 3.1 两个下降键怎么区分

- **加速（`↓`）**：按住生效，0.06s/格逐格下落（原 0.04s/格，按住时太快会像瞬间到底），不会立即锁定；按住期间按钮青色高亮，松开即停；每下落一格 +1 分。它解决的是“把方块快速送到落点附近，但仍可左右调整”。
- **落底（`⇓`）**：点按生效，直接移到幽灵位置并立即锁定；实心金色按钮 + 双箭头 + “落底”标签，和青色的加速键在颜色、图标形状、标签上都不同。触发时：
  - 画布 150ms 短促下沉 + 金色边框脉冲（`prefers-reduced-motion` 时关闭动画）；
  - 播放更低沉的 `slam` 音效（普通落地仍是 `land`）；
  - 支持的设备（主要是 Android）轻震 16ms；静音时不震动。
- **文案**：触屏提示直接写“↓ 按住加速 · ⇓ 点按落底”，键盘提示写“↓ 加速 / 空格落底”，不再让玩家猜两个下降行为的差别。

## 4. 不改变的东西

- 不改 `COLS` / `ROWS` / `CELL`、方块定义、7-bag、踢墙、计分、等级、锁定延迟、DAS 0.17s / ARR 0.05s；软降间隔从 0.04s 调到 0.06s，仅影响下降手感，每格 +1 分的规则不变。
- 不改 `runs:v1`、`progress:v1`、`prefs:v1` 等任何存储 key 或字段。
- 不改道路赛车 `road-pad` 的两键布局；新样式只挂在 `.block-pad` 下。
