# Arcade 0.8.6 设计：结算重新选模式 / 贪吃蛇双拇指相对转向

- 版本：Arcade `0.8.6`（`ARCADE_VERSION` / 注册表 / 中心页 / SW `VERSION` 同步）
- 日期：2026-11-19
- 状态：已实现；发布证据在双端部署核验后回填
- 范围：13 款游戏的经典/禅模式结算入口、`snake-run.html` 触屏方向控制、对应测试与版本文档；不改 localStorage key / Schema、挑战关卡数据或玩法数值。

## 1. 结算「再来一局」回到重新开始

### 复现

0.8.5 中，经典/禅模式结算的主按钮直接调用 `startGame` / `startZenRound`，玩家无法在不刷新页面的情况下改选当前游戏的其它模式。真实浏览器复现：贪吃蛇 20 果实结算后点击「再来一局」，状态直接从 `over` 变为 `playing`，弹层关闭。

### 新行为

| 场景 | 主按钮行为 |
| --- | --- |
| 13 款游戏经典局结算 | 「再来一局」打开该游戏开始弹层，重新选择经典或挑战模式 |
| 俄罗斯方块经典/禅模式结算 | 复用 `returnToStart()`，复位为 `mode='classic'`、`state='ready'`，再显示「开始游戏 / 挑战 6 关 / 🧘 禅模式」 |
| 2048 达成后的「继续挑战」 | 保留，继续当前盘，不是重开入口 |
| 挑战失败/通关 | 保留「重试本关 / 重玩本关 / 下一关 / 返回选关」，不强迫玩家绕回经典入口 |

俄罗斯方块禅模式结算原先另有「回到开始」；主按钮也回到模式选择后，两个入口功能重复，因此移除禅结算的第二按钮，只保留一个明确的「再来一局」。

所有游戏在结算时已经清理本局 `runs:v1` 并暂停循环，开始弹层不会错误出现「继续上次」。选择任一模式后仍走原有启动函数，积分、最高分和挑战记录语义不变。

## 2. 贪吃蛇：左右两个相对转向按钮

### 交互契约

触屏只保留左右两枚宽按钮：

- 左按钮 `↺ 左转`：相对蛇头当前方向逆时针转 90°。
- 右按钮 `↻ 右转`：相对蛇头当前方向顺时针转 90°。
- 不再提供绝对方向的 `← ↑ ↓ →` 四按钮；键盘、WASD 与滑动仍保留绝对方向控制。
- 按钮使用 `pointerdown` 立即响应，阻止默认行为与长按菜单；只在 `playing` 状态可用。

以屏幕坐标 `x` 向右、`y` 向下表示方向：

```text
左转 (x, y) → ( y, -x)
右转 (x, y) → (-y,  x)
```

例如蛇头向右时，右转变为向下；再按一次右转变为向左，而不是要求玩家按绝对方向的「下 / 左」。

### 快速连点与掉头约束

- 经典模式使用 `nextDir + queuedTurn` 两级待执行方向。连点基于待执行方向计算，但每移动一格只消费一次转向；不会在单一格内直接从向右切到向左。
- 第二个方向在下一格提升为 `nextDir`。键盘或滑动给出绝对方向时会清除这个触屏附加缓冲，避免旧输入覆盖最新意图。
- 挑战模式复用既有 `chDirQueue`（最多两步），按队列末尾方向计算下一次相对转向，继续由 `queueChallengeDir` 校验。
- `queuedTurn` 是瞬时输入，不写入存档；重开、复位与旧档恢复均为空。挑战队列的既有存档结构不变。

### 竖屏双手布局

- 两列等宽、左右分区，按钮间距 12px，最小高度 64px；左拇指只管左转，右拇指只管右转。
- 375×667 针对性实测每枚按钮 170×64 CSS px。
- 舞台可用高度扣减由 243px 调整为 249px，补偿按钮增加的 6px，保留 360×430 棋盘比例并避免页面纵向溢出。
- 320 / 375 / 390 / 430px 均纳入按钮尺寸、左右分区、棋盘尺寸与页面溢出自动检查；iOS/Android 真机手感仍需 Owner 试玩。
