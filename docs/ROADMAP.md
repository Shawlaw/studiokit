## Next

1. **Rounded Image**：用户曾提出圆角图片编辑/导出需求，但原 HTML 和完整规格暂未找回。先不要凭空复刻；等原需求补充后再确定功能边界。
2. **Tool discovery**：工具数量达到一定规模后，再考虑分类、搜索和标签过滤。
3. **Shared utilities**：只有出现两个以上真实重复实现时，才抽取文件下载、图片解码等公共能力。
4. **Optional PWA**：只有确实需要离线安装和缓存策略时再讨论，不作为 v0.1.0 的依赖。
