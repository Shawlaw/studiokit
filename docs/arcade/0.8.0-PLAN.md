## 4. 不变量与边界

- **保护既有资产**：13 款游戏、自动暂停/局内存档/触屏/全屏/PWA、0.7.0 主动道具与自然终点不得回退。
- **不改共享架构**：不改 `shared/`、不把 `engine.js` 提升为全站 shared；本竖切片只在 `apps/arcade/games/shadow-leap.html` 内实现挑战模式；`engine.js` 只允许在明确必要时做向后兼容的小改动，本次计划默认不改。
- **不引入依赖**：无 npm 包、无框架、无 CDN、无远程字体/图片/分析/后端；保持 `file://` 直接打开可玩。
- **存档兼容**：不新增 localStorage key、不改既有 key/Schema。影之试炼的进行中状态写入既有 `studiokit:arcade:runs:v1` 的 `data` 字段（旧档缺字段按经典模式恢复）；经典最高分与 `progress:v1` 不被挑战模式污染。
- **触屏最低要求**：主要动作独立按钮 ≥44×44 CSS px；`pointercancel`/`blur` 清理；320/375/390/430 宽无横向溢出；暂停/失焦不推进计时与物理。
- **无 FOMO**：无签到、每日奖励、体力、冷却、限时任务、连续在线奖励、跨局战力；挑战关卡可重玩、失败 2 次点击内重试。
- **提交纪律**：本地 Conventional Commits，一个提交一个意图；提交时间符合 `commit-time-policy` 窗口；**不 push/merge/tag/deploy**。
