# Arcade 0.8.2 实施契约：俄罗斯方块控制区压缩（给画布让出空间）

> 状态：执行中（Lead 维护）。Owner 试玩反馈原文：「模式没问题，但是按钮区占了太多游戏画面区域了，你想办法优化一下」。
> 目标版本：**Arcade 0.8.2**（0.8.1 的体验优化补丁）。发布仍为 GitHub Pages + Cloudflare Pages 双端。

## 1. 问题与目标

0.8.1 的俄罗斯方块在禅模式下有 **两行额外控件**（独立的 `.zen-bar` 冻结/结束行 + 道具行）与一行 hint，加上 5 键触控面板后，竖屏手机上控件区约占屏幕 40%+，画布被压得很小（实测 375×667 禅模式画布仅 184×325；320×568 仅 130×230）。

目标（必须全部满足）：
- 移除禅模式独立 `.zen-bar` 行，把「冻结/恢复提速」并入既有道具行（同一行，不增加行数）；「结束本局并记录」只保留在暂停弹层（已有），不再常驻。
- 禅模式隐藏重复的 hint 行（按钮与 HUD 已表达操作）。
- 压缩道具行高度（按钮仍 ≥44px）与间距。
- 结果：320/375/390/430 四档与桌面 1280×900 下，**禅模式画布高度比经典模式多 ≥40px**，且 `document.documentElement.scrollHeight <= innerHeight + 1`（无纵向溢出）、无横向溢出；控件按钮全部 ≥44px。
- 保留全部功能：冻结/恢复（触屏按钮 + 键盘 Z）、暂停「结束本局并记录」、结算「禅模式结束」、积分记录、存档恢复、经典/挑战零回归。

## 3. block-drop.html 实现规格

### 3.1 移除独立 zen-bar

- 删除页面 DOM：`<div class="zen-bar" data-zen-bar …>` 及其两个按钮。
- 删除页内 `<style>` 中 `.zen-bar`、`.zen-btn*` 规则与 `dom.zenBar/zenFreezeBtn/zenEndBtn` 引用。
- `body.has-zen-bar` 类保留（作为禅模式 CSS 钩子），仍只在 `mode==='zen'` 且 `playing/paused/clearing` 时添加。

### 3.2 冻结按钮并入道具行

- 在 `A.createToolbelt([...swap, slow...], { placement: 'below' })` 创建后，向 `joyTools.element` 追加一个按钮：
  - `<button type="button" class="tool-btn" data-zen-freeze hidden>`，内部 `<span class="tool-icon">❄</span><span class="tool-name">冻结提速</span>`；
  - **不要**加 `data-joy-tool` 属性（smoke 断言所有非矿工游戏 `[data-joy-tool]` 恰好 2 个，保持零改动）；
  - click → `toggleZenFreezeNow()`（仅在 zen + playing 生效，按钮 disabled 由 sync 管理）；
  - `aria-pressed` 反映冻结状态；`title`/`aria-label` 为「冻结提速」/「恢复提速」；class 可加 `is-frozen` 用于高亮。
- 非 zen（经典/挑战/ready/over）时按钮 `hidden`；zen 且 playing/paused 时显示（paused 时 disabled，paused 的结束走弹层）。
- 道具行网格列数：经典 2 列（`repeat(2, minmax(0,1fr))`），禅模式 3 列（`repeat(3, minmax(0,1fr))`）。由 `syncZenBar()` 内设置 `joyTools.element.style.gridTemplateColumns`，并保证在 startZen/startGame/startChallenge/exitChallenge/returnToStart/restore/pause/resume/settle 后被调用（这些路径大多已调用 syncChallengeHud → syncZenHud + syncZenBar，检查补齐）。
- 键盘 Z 逻辑保留；删除旧的 zen-bar 按钮监听与 `bindZenControls` 中的对应部分（保留 Z keydown 监听）。

### 3.3 CSS 压缩（页内 `<style>`，只用 body 类限定本页）

```css
/* 禅模式 hint 冗余：HUD + 画布内标签已提示操作 */
body.has-zen-bar .block-hint { display: none; }

/* 道具行压缩（经典/禅模式共用；按钮仍 ≥44px） */
body.has-joy-row .joy-tools-below { gap: 6px; margin-top: 2px; }
body.has-joy-row .joy-tools-below .tool-btn { min-height: 44px; padding: 2px 4px; }
```

### 3.4 画布高度回收（页内 `<style>`）

把现有两条 `body.has-zen-bar… .stage-box` 的 height 覆盖常量从 `302px`/`298px` 改成新值（初始建议 `202px`/`198px`），保留宽度上限公式：

```css
@media (min-height: 561px) {
  body.has-zen-bar.has-joy-row.has-extra-controls:not(.arcade-immersive) .stage-box {
    height: min(
      calc(100dvh - var(--studiokit-shellbar-h, 0px) - 202px - env(safe-area-inset-bottom, 0px)),
      calc(min(520px, 100vw - 24px) * 740 / 420)
    );
  }
}
@media (min-height: 561px) and (max-width: 360px) {
  body.has-zen-bar.has-joy-row.has-extra-controls:not(.arcade-immersive) .stage-box {
    height: min(
      calc(100dvh - var(--studiokit-shellbar-h, 0px) - 198px - env(safe-area-inset-bottom, 0px)),
      calc(min(520px, 100vw - 16px) * 740 / 420)
    );
  }
}
```

实现者必须用真实无头浏览器测量并按结果微调常量：目标 `docH <= vh + 1` 且尽量接近 vh（保留 2–4px 余量），四档手机宽度 + 1280×900 都满足；`zenStageHeight - classicStageHeight >= 44`。注意 1280×900 桌面宽度上限为 `min(520px,100vw-24px)*740/420`（≈916），height 公式生效，因此同样适用。

### 3.5 不可破坏

- 经典 40 行收局、挑战 C01–C06、道具 1/2、道具次数/慢落、#test 钩子（`info/zenInfo/startZen/toggleZenFreeze/zenSetState/zenLineClearScenario/endZen`）、`runs:v1` 存档/旧档兼容、结算与积分记录全部保持。
- `[data-joy-tool]` 数量仍为 2（经典与禅模式均如此；冻结按钮不带该属性）。
- 页内脚本 `node --check`（抽取内联 script）通过；`git diff --check` 干净。
