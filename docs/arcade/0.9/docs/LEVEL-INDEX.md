## 验证范围

- 俄罗斯方块/2048：参考操作由独立规则模拟器回放验证。
- 贪吃蛇：参考转向由蛇身 BFS 生成并逐格复放，包含尾部占用及长度增长。
- 极速车道：基于离散时隙的车道邻接路径验证，真实变道过渡碰撞仍需引擎检查。
- 黄金矿工：参考抓取价值与直线目标前方障碍检查，钩爪时间/物理须进一步验证。
- 影跃/雪铃/重力翻转/层塔/弹幕/打砖：静态结构合理性检查，不等同物理可玩性证明。

运行：`python3 scripts/validate_levels.py`。
