# 05｜0.8.0 正在开发：并行治理和差异核对清单

## 强制隔离

**用户当前状态**：0.8.0 还在开发。此包不是0.8.0的新 patch，不应在 Agent 开工时用它替换既有 GP001–GP023/同类任务，也不能推断0.8.0已经有/没有某个具体接口。

1. 先 `git status --short`, `git log -1 --oneline`, 查看当前分支、未提交改动、在办任务。只读检查。
2. 阅读 0.8.0 的完成状态和实际代码（不是仅看旧PRD）。列出13款已落地能力及本包对应差异。
3. 输出 `0.8.0->0.9.0 DIFF REPORT`：保留/复用/需新增/已冲突/需 Owner 决策的字段。
4. **Owner 授权后**从稳定的 0.8.0 基线单独开 `feat/arcade-0.9-gameplay`；本包不负责自动切分支。
5. 0.9 初始 PR 只增加模式/数据适配/测试，不变更经典核心逻辑和历史存档。
6. 先《影跃》C01–C03 完成竖切片，Owner 试玩后再放行 C04–C06 及其他游戏。

## 0.8.0 可能已经覆盖的部分

影冲、挑战模式、首批关卡、支线卷轴/分岔、阶段Boss等**先查是否已经有**。已实现的机制优先映射新关卡数据；禁止只是为了字段统一而重新开发第二套。

| 需核查 | 若0.8已实现 | 若尚未实现 |
|---|---|---|
| `challenge` 模式 | 适配现有 mode | 最小新增独立入口 |
| `stageId` / 关卡选择 | 复用 | 小型关卡列表（不做大地图） |
| 影冲 | 复用现有输入和固定帧技能 | 只实现一次，修复回放并发 |
| 关卡数据 | 写转换层 | 在每游戏独立文件里加载预设参数 |
| 自动存档 | 扩展存档版本并验证迁移 | 保留原Autosave，增关卡字段 |
| 关卡通关评价 | 接已有UI | 最小完成弹层和本地记录 |

## Conflict 处理原则

- 0.8已完成关卡如与本包重复：对比事实，不自动覆盖；策划可用另一 ID，或由Owner批准做迁移。旧玩家存档/成绩永不静默丢失。
- 0.8还未合并的改动：不要抢改同一个 games/*.html；本包只讨论和修订独立蓝图。
- 关卡 schema 与 0.8 冲突：先写 adapter，不让 13 款分别独立发明字段。
- 任一固定关不可达/不可完成：允许数值调参，**必须提交差异表，写下为什么改变，得到 Owner/Reviewer 同意**，而不是自己悄悄更换关键路线或目标。
