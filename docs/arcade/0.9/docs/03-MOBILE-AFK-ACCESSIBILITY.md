# 03｜移动端、AFK 与无障碍设计合同

## 基础设备验收

- 320×568、375×667、390×844、430×932 CSS px；至少一部 Android Chrome 与一部 iOS Safari（模拟测试不能替代真机）。
- 横屏、地址栏展开/收起、全屏进出、PWA 安装启动、屏幕安全区 `env(safe-area-inset-*)`、dpr=1/2/3 下画面和命中坐标一致。
- 不把按钮盖在画布关键碰撞区。触控热区至少 44×44 CSS px，建议高频动作 48×48；可视觉图标较小、可点击区域充足。
- 游戏画布可 `touch-action:none`，**不是整个网页**禁止缩放/滚动；老年/低视力用户系统缩放应可用。

## 每款游戏的手机操作方案

| 游戏 | 首选手机动作 | 单手/双指 | 易错点要测 |
|---|---|---|---|
| 影跃 | 独立左右区 + 影冲大按钮 | 左按住右影冲 | 多指 pointerId 不粘住，影冲按钮不误触羽落/月弹 |
| 雪铃 | 画布左右按住，目标高亮 | 单/双手可达 | 目标被手遮挡、铃按顺序仍能碰撞 |
| 星海突击 | 拖拽飞机，独立主动道具 | 一指拖拽+一指道具 | 拖动不触发射击以外的点击，子弹密度可见 |
| 层塔 | 单击释放，低频道具另区 | 单手 | 点击区不被广告/导航/软键盘挤压；放箱反馈清楚 |
| 俄罗斯方块 | 左/右、旋转、软降、硬降独立按键 | 拇指可及 | 硬降不等于软降，旋转不可误触暂停 |
| 极速车道 | 左右大按钮/左右滑动择一 | 单手 | 一次手势只换一车道，禁连点跳两道造成误判 |
| 黄金矿工 | 点击释放；明确的瞄准/道具区 | 单手 | 瞄准模式松手不误放钩 |
| 砖块计划 | 拖动挡板，单击/独立发球 | 单指 | 拖拽挡板不会自动发球，挡板不会因惯性跳边 |
| 重力翻转 | 大点击区/一个翻转按钮 | 单手 | 状态暂停后首触不应误翻转 |
| 贪吃蛇 | 四向滑动或可选方向键 | 单手 | 两次快速90°方向输入按步执行、180°反转拒绝 |
| 打地鼠 | 3×3洞口直接点击 | 一/双手 | 同时两指敲不同洞，洞口距边界足够大 |
| 记忆翻牌 | 直接点卡 | 单手 | 翻开过渡期双击不能错计翻牌 |
| 2048 | 方向滑动 | 单手 | 斜方向阈值稳定，画布外正常滚动 |

## AFK 细则

暂停发生在 `blur`, `visibilitychange(hidden)`, `pagehide`, 设备锁屏与 PWA 切后台。保存应包括本关剩余倒计时、已收集/已击中对象、机关状态、随机种子或固定事件游标、玩家动量、技能库存、动画阶段。

恢复必须显示一个中断可见的「继续」覆盖层，必要时先给 1–2 秒安全提示（不计入有效时间）；不能后台继续消耗剩余时间或连击。刷新恢复与主动重开必须是两个明确选项。

## 输入取消

`pointercancel`、`lostpointercapture`、blur 必须释放每个指针占用的移动/技能动作；禁止“左键永久按住”。全屏切换后不能重复绑定事件导致一次点击触发双动作。

## 可访问性

- 关键风险颜色同时提供**形状/纹理/文字图标**；例如金鼠是星形轮廓，炸药是叉形爆炸标识，雪铃红/蓝也有不同形状。
- 失败原因可读；静音模式也有视觉提示。`prefers-reduced-motion` 降低屏幕摇晃/闪白但不改变判定。
- 无必须开启声音才能识别的节奏；字幕/图标先兆和音效同步。
- 暂停/音量/退出不会发生不可逆转的即时误操作，回到游戏可重复操作。
