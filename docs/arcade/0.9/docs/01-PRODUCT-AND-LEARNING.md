# 01｜产品定位、游戏性与关卡学习曲线

## 产品支柱

1. **短**：单关推荐 30 秒–3 分钟，复杂第六关最高约 3 分钟；重来两次点击内完成。
2. **深**：每款游戏有一项技巧可提高，至少一次真正的取舍（稳妥/高回报、观察/立即执行、最少步数/更多容错）。
3. **不绑人**：不登录、不追日活、不惩罚断签、不卖数值、不靠限定活动催回归。
4. **可离开**：后台暂停与恢复是基础合同；不因失焦损失连击、生命、倒计时。
5. **尊重经典**：原有 `classic/endless` 不被挑战模式修改；新谜题只是同名游戏的第二种入口。

## 六关学习曲线（每游戏默认）

| 关序 | 设计角色 | 强制区分点 | 玩家获得的能力 |
|---|---|---|---|
| C01 | 认识动作 | 单一核心动作，低失误成本 | 30秒内明白规则 |
| C02 | 稳定执行 | 角度/路线/优先级明确 | 学会下一步前先观察 |
| C03 | 引入新冲突 | 机关/陷阱/动作组合 | 能解释失败原因 |
| C04 | 分支/策略 | 两条可行路线或解题顺序 | 主动选择而不纯跟随 |
| C05 | 综合应用 | 前述机制组合/高风险奖励 | 能重复练习而有提高 |
| C06 | 小型毕业考 | 对技巧的综合测试 | 1–3分钟内完成可归因挑战 |

该结构不是硬性要求新发明六种道具。每关最好只新增一个新认知负担，让旧技巧在新语境下复用。

## 13款游戏如何定义“探索”

- 影跃/雪铃：真实分叉和奖励路径、可选卷轴/彩铃。奖励不强化人物数值。
- 星海：识别攻击模式、安全走廊、输出窗口与拾取路径。
- 层塔：不同偏心安排如何影响结构、学习看重心而不是瞎点。
- 俄罗斯方块/2048：发现更短解法与局面不变量，不要加战斗或奖励货币。
- 极速车道：提前看车流与施工模式，观察高分近距超车与普通避让的区别。
- 黄金矿工：同一矿图下的时间最优角度与优先顺序。
- 砖块计划：挡板偏心带来不同反弹路线，钥匙砖开启侧路。
- 重力翻转：学习危险间隔的节奏、选择收星与不收星的路线。
- 贪吃蛇：读地图连通性、提前留出口。
- 打地鼠：看预警、鉴别金鼠/炸弹/假目标，学会不乱点。
- 记忆翻牌：分区编码、使用线索和规律推理。

## 公平性四条红线

- 有理可解释：看见预警/规则提示才能被要求反应；不得无预警瞬间致命。
- 必经可达：任一“必须做”的行动至少有一条无付费/无有限道具的通关路径。
- 重试公平：同关默认同一布局/脚本，容许玩家复盘；变化仅作为玩家可选择的“随机挑战”。
- 辅助诚实：用辅助可通关；挑战成绩标记 assisted，不与标准成绩强混。

## 上手评价卡

每关必须能回答：**为什么现在要这样操作？如果失败，下次具体改哪里？高手的策略和新手有何不同？** 只把速度/血量改大却无法回答则退回设计。
