# 06｜难度与策划变更治理

## 设计参数与真实物理边界

本包坐标和时间轴是 v1 **候选值**，不是对未开发的0.8/0.9引擎做过全自动回放的通过值。设计固定的是**关卡意图、玩家选择、目标、路线结构、物理公平性**；数字应经仿真、真机测试调到可过。

| 设计内容 | 可允许调节 | 未经批准不可删除 |
|---|---|---|
| 平台/铃点 | x±20px、h±12px、宽度±15%、周期±20%（通过审查后可超限） | 主线与支路、新技巧必要性、藏品非强制 |
| 弹幕/车阵 | 预警+0.3s、子弹速度±15%、占用时段微调 | 真正安全走廊、需观察可做决定 |
| 矿工 | 钩爪时间限制和矿物位置±18px | 参考价值达标、时间取舍、炸药可预见 |
| 叠塔 | 钟摆速率、标记偏置及容差 | 真正物理偏心计算、零自动吸附 |
| 重力/砖块 | 障碍间距或挡板速度±15% | 技巧型解法、无随机不合理死亡 |
| 俄罗斯方块/2048 | 固定盘面和参考解仅在证明不能按引擎通关时调整 | 经典原规则、关卡有解且解题过程需玩家策略 |
| 贪吃蛇/记忆/打地鼠 | 预览/反应窗、障碍分布、限制数 | 可解性、可读性、无无预警惩罚 |

所有变更需在对应任务的 `design-diff.md` 中记录旧→新与依据，拒绝“随手调小一点/玩家太菜”的无证据结论。

## 难度不是单一数值

- **新知识数量**：一关新教一个东西，并为该技巧留下安全练习段。
- **执行窗口**：先保证玩家看得清，再缩短操作窗口，严禁连关偷偷改物理手感。
- **重试成本**：难关允许练习，但失败应快速重试，避免反复等待开局动画。
- **策略空间**：手快不是唯一能力。相同关卡提供稳妥与高效方案；隐藏内容不拦主线。
- **流畅度**：首玩被难住可以接受，完全不知道为什么失败不接受。

## 人工抽样建议（不是已测结论）

每款至少三人/三种控制方式：不了解规则的新手、玩过一两轮的普通玩家、愿意钻研的熟练玩家。录制**首关首次体验、第三关首次接触新机制、第六关练习后复盘**。

每关记录：首次完成时间/尝试次数、失败分类（误触/未读提示/动作误差/死局/真规则不懂）、第二轮表现增量、是否发觉可选路径或解法；对不同人分别看趋势，避免仅凭平均值判断。

## 自愿娱乐边界

不设计强制每日奖励、已购道具倒计时、缺席惩罚、连续打卡流失提示、稀缺性强迫，不把小游戏做成日常任务平台。评价时不追求最大化在站时长，而是“短时间的体验完整性和主动重玩理由”。
