# 贪吃蛇｜6 关可实施蓝图

- 游戏 ID：`snake-run`；当前公开主干对应文件：`apps/arcade/games/snake-run.html`
- 数据源：`../levels/snake-run.json`，每关单文件在 `../levels/stages/snake-run-Cxx.json`
- 实施对象：独立 challenge mode，经典模式原样保留；关卡表达：18×18障碍/水果/蛇身路线
- 状态：策划版，已运行静态校验；未经过当前引擎物理模拟和真机测试。

## 章节总览

| # | 关卡 | 目标 | 技巧 | 发现 |
|---:|---|---|---|---|
| 1 | 果园初识 | 读懂长度、转弯和正向移动 | 保持出路，不要向自身尾部硬反转 | 安全区有明显回环空间 |
| 2 | 中央小门 | 选择跨墙缺口，而不是贴墙盲走 | 提前把蛇头朝向门口 | 找到中央唯一可通过缺口 |
| 3 | 双柱回廊 | 先观察柱子的出入口 | 用转向序列穿过狭窄走廊 | 上门/下门构成不同路线 |
| 4 | 环形果园 | 从两个门往返内外环 | 绕行不等于坏选择，保护回头空间 | 门分布构成内外两种通道 |

## 逐关详细规格

1. **成功路径**：完整蛇身状态搜索能从开局按给定水果序列安全通关
2. **失败路径**：若蛇身增长后堵死果实则必须修改地图/果实或增加提示，不能靠道具脱困
3. **移动端**：滑动方向按步缓存，连续两个90°输入都生效，反向自杀被拒绝
4. **AFK**：任一有效游玩时刻切后台/锁屏/恢复，剩余时间、玩家位置与未完成目标不变化；恢复后手动继续
