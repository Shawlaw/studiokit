## 逐关详细规格

### C01 · 中路开门

- **通关目标**：使球从中央缺口穿入顶部，消除所有砖
- **关卡决策**：球正中打挡板 vs 偏心打挡板
- **练习重点**：掌握击球位置对角度的影响
- **探索反馈**：观察中间两列形成天然反弹通路
