## 刻意不声明通过的项目

- **物理引擎验收**：影冲动量、可实际命中铃铛、移动平台回弹、钩爪摆速/回收速度、弹幕碰撞安全带、重力翻转、砖块反弹角、层塔结构稳定。
- **动态路线验收**：赛车变道过程车宽和过渡帧中的瞬时碰撞；离散路径已通过但不足以证明真实驾驶轨迹安全。
- **设备验收**：真实 Android Chrome/iOS Safari 的触屏、多指、刘海安全区、失焦续玩，均未在本次仅设计文件的任务中执行。
- **娱乐性验收**：需要 Owner 实际试玩，不能由数据测试推断“好玩”。

以上未验证项作为交付 **必须执行的 Gate**，在 `docs/04-PLAYTEST-QUALITY-GATES.md` 和单关 acceptance 均有明确记录，不允许 Agent 把它们标成已完成。

## 发现并修正的问题（设计阶段已修）

1. 《极速车道》某版“左右交替”车流没有完整相邻变道路径，改为可连续行驶且仍能产生路线选择的时隙布局。
2. 《2048》一版最终残局在限定步数内无解，换成有四步参考解的局面。
3. 《俄罗斯方块》一版 T 型锁孔虽几何匹配，但无法从顶部实际硬降进入；改用可由规则模拟器真实填充并消行的 T 型腔体，同时修正复合关卡。
4. 《影跃》一段支线的高度跨度超过无辅助跳跃的理论极限，加入中继平台。
5. 《黄金矿工》参考射线可能先命中路过矿物/石块，调整位置避免已知直线遮挡。
6. 《砖块计划》一张砖图行数不足，补齐独立空行。

**结论：交付已达到“可以开始工程适配与逐关回放”的策划资料级别；没有达到“已实机保证78关可过”的软件成品级别。**
